# an1mbyt3-text

Font shaping (`rustybuzz`) + glyph atlas/SDF generation + glyph mesh output,
cached the same way path tessellation is cached (AN1MBYT3_BUILD_PLAN.md §6, §10 Phase 3).

**Depends on:** `an1mbyt3-core`, `an1mbyt3-geometry`, `an1mbyt3-renderer`.
**Depended on by:** `an1mbyt3-wasm`, the Tauri editor (`apps/editor`).
