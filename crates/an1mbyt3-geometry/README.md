# an1mbyt3-geometry

Paths, Bézier curves, tessellation, meshes, and deformation math. Turns vector
path data from `an1mbyt3-core` into GPU-friendly triangle meshes, with
tessellation results cached per shape (see AN1MBYT3_BUILD_PLAN.md §6).

**Depends on:** `an1mbyt3-core`.
**Depended on by:** `an1mbyt3-runtime`, `an1mbyt3-constraints`, `an1mbyt3-renderer`, `an1mbyt3-text`.

## Status

Not yet implemented — Phase 1 (AN1MBYT3_BUILD_PLAN.md §10).
