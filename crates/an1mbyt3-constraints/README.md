# an1mbyt3-constraints

Bones, IK (CCD/two-bone analytic first, FABRIK later), aim/look-at, follow,
distance, and transform constraints. Evaluated in dependency-sorted order after
base transforms, before rendering. See AN1MBYT3_BUILD_PLAN.md §5.

**Depends on:** `an1mbyt3-core`, `an1mbyt3-geometry`.
**Depended on by:** `an1mbyt3-format`, `an1mbyt3-wasm`.

Not yet implemented — Phase 5 (AN1MBYT3_BUILD_PLAN.md §10).
