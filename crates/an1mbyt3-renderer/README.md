# an1mbyt3-renderer

wgpu-based rendering: shaders, batching, culling, masks, compositing, blend
modes. The only crate that touches the GPU. See AN1MBYT3_BUILD_PLAN.md §6.

**Depended on by:** `an1mbyt3-text`, `an1mbyt3-wasm`, the Tauri editor (`apps/editor`).
