# 2. The menu icon

**Goal:** three bars that fold into a close icon when `open` is true. The top and bottom bars slide to the middle and rotate to ±45°; the middle bar collapses into its own centre with a trim path. Then you wire it to a mobile navigation with `aria-expanded`.

## Steps

### 1. Draw one bar, then copy it

Each bar must be its own node whose **Position** places it, because the animation moves and rotates each bar around its own centre. So import a single centred bar and copy it, rather than importing three bars at once (the SVG importer bakes positions into the path, and the bars would then rotate around the scene centre).

Start from your template scene (lesson 1), name the scene `Menu`, then import:

```svg title="bar.svg"
<svg xmlns="http://www.w3.org/2000/svg" viewBox="-48 -48 96 96" width="96" height="96">
  <path id="top" d="M-20 0 L20 0" fill="none" stroke="#1C1C21" stroke-width="5" stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

1. Select `top`, add a **Stroke Style (dash, trim path)** and set **Dash** to `0`.
2. Press **Ctrl+C**, then **Ctrl+V** twice. Rename the copies `middle` and `bottom` (the Stroke Style is copied with them).
3. Set **Position**: `top` at Y `13`, `middle` at Y `0`, `bottom` at Y `-13`. X stays `0` for all three.
4. Select the three bars and press **Ctrl+G**. Rename the group `bars`.
5. Make sure `hit` is still the top row in Layers.
6. Select each bar, add **Property Binding**, and bind `ink` → **Stroke colour**.

### 2. Two animations

| Animation | Dur | Role |
|---|---|---|
| **Animation 1** | 0.3 s | Closed (rest pose) |
| **Animation 2** | 0.5 s | Open |
| **Animation 3** | 0.2 s | Hover off |
| **Animation 4** | 0.2 s | Hover on |

**Closed** (all keys at 0 s):

| Node | Value at 0 s |
|---|---|
| `top` | Position (0, 13), Rotation 0 |
| `bottom` | Position (0, -13), Rotation 0 |
| `middle` | Trim start 0, Trim end 1 |

**Open:**

| Node and value | 0 s | 0.16 s | 0.2 s | 0.42 s |
|---|---|---|---|---|
| `top` Position | (0, 13) | | (0, 0), curve InOut | |
| `top` Rotation | 0 | 0 | | 45, curve Back |
| `bottom` Position | (0, -13) | | (0, 0), curve InOut | |
| `bottom` Rotation | 0 | 0 | | -45, curve Back |
| `middle` Trim start | 0 | | 0.5, curve Out | |
| `middle` Trim end | 1 | | 0.5, curve Out | |

Position and Rotation use their own Timeline rows: pose in the Inspector, then press **+** on the row. The trim values key themselves with **Rec** on.

**Hover off / Hover on:** `bars` **Scale %** `100` and `108`, one key each at 0 s.

### 3. The state machine

1. **New State Machine** `Machine`. Declare `open` (**Bool**) and `hover` (**Bool**).
2. Base: State 1 = Animation 1 (Closed), **Once**. **+ Add State**: Animation 2 (Open), **Once**.
3. Closed → Open: **Boolean is** `open`, **Required value** ticked, **Crossfade (s)** `0`.
4. Open → Closed: **Boolean is** `open`, unticked, **Crossfade (s)** `0.28`.
5. **+ Layer** `Hover`, mask `bars`. Rest (Animation 3) → Over (Animation 4) on `hover` true, **Crossfade (s)** `0.16`; back on false, `0.2`.

### 4. Click toggles `open`

Select `hit`. In **On Click ()**, **+ Add action** → **Toggle input (Bool)** → `open`. Check the Pointer Listeners point at `hover`. Export with **Export → Animation → Toasty Lite (.json)** as `menu.json`.

## Use it: a mobile navigation

The page owns `open`, exactly like the like button: the icon has `pointer-events: none` and the `<button>` handles clicks, keyboard and `aria-expanded`. Escape and a click on a link close the menu.

        ))}
      </nav>
    </>
  )
}`}

## How it works

- **Each bar rotates around its own centre** because its path is centred on the node origin and its Position puts it in place. Moving the top bar from Y 13 to Y 0 and rotating it 45° leaves it crossing the centre of the icon.
- **The rotation waits for the slide.** Rotation keys hold 0 until 0.16 s, so the bars first meet in the middle (0 to 0.2 s), then turn (0.16 to 0.42 s). The overlap of 0.04 s keeps it fluid. The Back curve overshoots past 45° and settles, which reads as a snap.
- **Trimming to the centre.** Moving Trim start from 0 to 0.5 and Trim end from 1 to 0.5 at the same time shrinks the middle bar from both ends into its midpoint. A trim path can collapse a line in any direction this way: toward the start (end → 0), toward the end (start → 1), or toward a point.
- **Closing is a crossfade, not a rewind.** Open → Closed blends to the rest pose over 0.28 s. The bars straighten and spread in one gesture.

## Check your work

- In the State Machine tab, ticking `open` draws a clean ✕ with both diagonals crossing at the centre.
- Unticking `open` mid-animation blends back without a jump.
- In the live example, Tab to the menu button, press Enter, then Escape: the menu opens, focus moves to the first link, and Escape closes it and returns focus.
