# 5. Theme them all with ink

**Goal:** every icon in the set matches the page, in light mode, in dark mode and in brand colours, without editing the files. This works because each icon you built binds its line colour to the same property, `ink`.

## Four ways to set `ink`

| Where | How | Follows theme changes |
|---|---|---|
| HTML attribute | `<toasty-lite ink="currentColor">` | Yes. Re-read when `<html>` changes its `class`, `data-theme` or `style`, and when the system colour scheme changes. |
| HTML attribute | `<toasty-lite ink="#2563eb">` (any CSS colour) | No, it is a fixed colour. Change the attribute to change it. |
| JavaScript | `el.player.set('ink', '#2563eb')` or `player.set('ink', [0.15, 0.39, 0.92, 1])` | No. Call it again when your theme changes. |
| React | `<ToastyLite ink="#2563eb" />` (any CSS colour string), or `data={{ ink: '#2563eb' }}` | When you pass a new value. |

The `ink` attribute accepts anything CSS accepts as a colour, because the element resolves it through the browser. `player.set` and `data` accept a `#rrggbb` string or an `[r, g, b, a]` array with values from 0 to 1.

## How it works

- **One property, every icon.** Because every line icon in the set binds `ink` to its **Stroke colour**, one attribute themes each of them, and one selector can theme the whole page.
- **`currentColor` is resolved by the browser.** The element measures the CSS colour it inherits, so it respects your CSS cascade: a toolbar can be dark while the page is light, and a pressed button can turn its icon red, as the like button did.
- **Accent colours stay fixed.** Only the lines bound to `ink` change. The red heart fill, the green checks and the amber progress ring keep their meaning in every theme. The theme icon has no `ink` at all.
- **Two kinds of icon in one toolbar.** The menu, copy and bell icons here keep their own built-in clicks: they toggle, confirm and ring by themselves. The theme icon has `pointer-events: none`, because the page owns the theme. Choose per icon, depending on whether the page needs to know.
- **React passes a colour string.** `<ToastyLite>` takes an `ink` prop with any CSS colour. Derive it from your theme state; changing it updates the running icon without a reload. (The prop sets a fixed colour, so pass a new one when the theme changes.)

## Check your work

- Switching the docs between light and dark mode recolours the four toolbar icons.
- The moon icon in the frame does the same for the frame only, and its own animation plays.
- Choosing **Text colour** in the brand menu makes the bottom row follow the theme as well.
