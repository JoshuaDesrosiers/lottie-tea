# 3. A mood blob that reads the form

**Goal:** a sign-up form whose mascot frowns at a weak password, brightens as it gets stronger, and jumps for joy when you sign up.

**What you'll learn**

- Turning form state into one number for the scene.
- Writing a value on every keystroke (it's cheap).
- Easing a value on the page for smoother motion.
- Triggers for moments: `jump` on success.
- Using the scene's `poke` event for a playful extra.

## Step 1: password strength as a mood

The blob understands one number, `mood`, from −1 (sad) through 0 (neutral) to 1 (happy). Any form signal can be mapped to it. Password strength is a fun one:

```ts title="src/passwordMood.ts"
/**
 * A rough password score, 0..5: length, and a mix of character kinds.
 * (For real strength checks use a proper library such as zxcvbn;
 * this is about the feedback, not security.)
 */
export function passwordScore(pw: string): number {
  if (!pw) return 0
  let score = 0
  if (pw.length >= 8) score++
  if (pw.length >= 12) score++
  if (/[a-z]/.test(pw) && /[A-Z]/.test(pw)) score++
  if (/\d/.test(pw)) score++
  if (/[^A-Za-z0-9]/.test(pw)) score++
  return score
}

/** Score 0..5 -> mood -1..1. Empty means neutral, not sad. */
export function moodFromPassword(pw: string): number {
  if (!pw) return 0
  return -1 + (passwordScore(pw) / 5) * 2
}
```

## Step 2: the form

```tsx title="src/SignupHero.tsx"
import { useRef, useState, type FormEvent } from 'react'
import { An1Player, type An1PlayerHandle } from './an1mbyt3/an1mbyt3-react.js'
import { moodFromPassword, passwordScore } from './passwordMood'

export function SignupHero() {
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [status, setStatus] = useState<'idle' | 'sending' | 'done' | 'error'>('idle')
  const player = useRef<An1PlayerHandle | null>(null)

  // After a successful sign-up the blob stays delighted.
  const mood = status === 'done' ? 1 : status === 'error' ? -0.6 : moodFromPassword(password)

  async function submit(e: FormEvent) {
    e.preventDefault()
    setStatus('sending')
    try {
      const res = await fetch('/api/signup', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ email, password }),
      })
      if (!res.ok) throw new Error(String(res.status))
      setStatus('done')
      player.current?.fire('jump') // a moment, so a trigger
    } catch {
      setStatus('error')
    }
  }

  return (
    <section className="signup">
      <An1Player
        game="/an1mbyt3/game.teab"
        style={{ width: 240, height: 240 }}
        data={{ mood }}
        onReady={(p) => (player.current = p)}
        onEvent={(e) => {
          // Poking the blob while it's sad gets a sympathetic hint.
          if (e.name === 'poke' && (e.payload as { mood: number }).mood < 0) {
            alert('Try a longer password with numbers and symbols!')
          }
        }}
      />
      <form onSubmit={submit}>
        <input type="email" required placeholder="you@example.com" value={email} onChange={(e) => setEmail(e.target.value)} />
        <input type="password" required placeholder="Password" value={password} onChange={(e) => setPassword(e.target.value)} />
        <meter min={0} max={5} value={passwordScore(password)} />
        <button disabled={status === 'sending' || passwordScore(password) < 3}>Sign up</button>
        {status === 'done' && <p>Welcome aboard!</p>}
        {status === 'error' && <p role="alert">Something went wrong. Please try again.</p>}
      </form>
    </section>
  )
}
```

## Try it live

Type a password and watch the blob. The "Sign up" here pretends to succeed after half a second.

```jsx live
function MoodForm() {
  const [password, setPassword] = React.useState('')
  const [done, setDone] = React.useState(false)
  const [state, setState] = React.useState('')
  const player = React.useRef(null)

  const score = (pw) => {
    if (!pw) return 0
    let s = 0
    if (pw.length >= 8) s++
    if (pw.length >= 12) s++
    if (/[a-z]/.test(pw) && /[A-Z]/.test(pw)) s++
    if (/\d/.test(pw)) s++
    if (/[^A-Za-z0-9]/.test(pw)) s++
    return s
  }
  const mood = done ? 1 : password ? -1 + (score(password) / 5) * 2 : 0

  return (
    <div style={{ display: 'flex', gap: 24, flexWrap: 'wrap', alignItems: 'center' }}>
      <ToastyPlayer
        game="/games/mood-blob.teab"
        style={{ width: 240, height: 240 }}
        data={{ mood }}
        onReady={(p) => (player.current = p)}
        onStateChange={(e) => setState(e.state)}
      />
      <form onSubmit={(e) => {
        e.preventDefault()
        setTimeout(() => { setDone(true); player.current?.fire('jump') }, 500)
      }}>
        <input type="password" placeholder="Password" value={password}
          onChange={(e) => { setPassword(e.target.value); setDone(false) }} />
        <p>Strength {score(password)}/5, mood {mood.toFixed(2)}, blob is <b>{state}</b></p>
        <button disabled={score(password) < 3}>Sign up</button>
      </form>
    </div>
  )
}
```

## How it works

- **One number.** The page squeezes the whole form into `mood`. The scene decides what −0.2 or 0.6 looks like and when it counts as `Sad`, `Neutral` or `Happy`. You can change the mapping without touching the scene, and the artist can change the blob without touching your form.
- **Every keystroke.** `data={{ mood }}` re-renders on each key; `An1Player` only sends a value when it changed. There's no need to debounce.
- **Triggers for moments.** "Signed up!" happens once, so it's `fire('jump')`, not a value. A Property set to `true` would only "happen" the first time.
- **`poke`.** The blob tells the page when it's clicked, and how it felt at that moment. The page decides whether that means anything.

:::tip Smoother moods
The mood jumps in steps of 0.4 as the score changes. If you want the value to glide instead, ease it on the page: keep a `shown` value and move it toward the target in a `requestAnimationFrame` loop (`shown += (target - shown) * 0.15`), sending `shown`. Sending a value 60 times a second is fine.
:::
