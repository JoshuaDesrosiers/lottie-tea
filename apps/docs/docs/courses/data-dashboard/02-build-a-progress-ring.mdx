# 2. Build a progress ring

**Goal:** a progress ring you can drive entirely from page data, built mostly with bindings.

**What you'll learn**

- Drawing an arc with a stroke and **Stroke Style**'s trim.
- Binding a Property to a component field (`StrokeStyle2D › trimEnd`).
- Binding Text and Fill colour.
- A Bool input set from data with `ctx.setInput`, so states follow values.
- Emitting a one-time `done` event.

## Step 1: the scene

1. New scene (**Scene** dropdown → **+ New Scene**), name it `Progress`. With nothing selected, set **Size** to `240` × `240`.
2. **+ → Camera**. Tick **Main Camera (Playground views through this)** and pick a **Background** matching your page.

## Step 2: the track and the arc

1. **+ → 2D Object → Ellipse**. Name it `track`. Give it no visible fill (make the fill colour fully transparent) and a **stroke** about `14` wide in a pale grey. This is the empty ring.
2. Copy and paste it in place (**Ctrl+C**, **Ctrl+V**). Name the copy `ring` and set its **Id** to `ring`. Give its stroke your accent colour, e.g. `#7c5cff`.
3. With `ring` selected: **Add Component → Effects 2D → Stroke Style (dash, trim path)**. Set **Dash** to `0` (a solid line) and drag **Trim end** between 0 and 1: the arc grows around the ring.
4. Turn the ring so the arc starts at 12 o'clock with its **Rotation** (try `90`). If it fills anticlockwise and you want clockwise, set **Scale X** to `-1`.

## Step 3: the texts and the tick

1. **+ → 2D Object → Text** for the percentage: text `35%`, size about `40`, centred. **Id** `percent`.
2. Another Text under the ring: text `Uploading`, size about `14`. **Id** `caption`.
3. **+ → 2D Object → Icon (Material Symbols)**, set the icon to `check`, size about `48`, at the centre. **Id** `check`. Leave it where it is: the script hides it while loading and shows it when done.

## Step 4: Properties

With nothing selected, under **Properties**:

| Add | Rename to | Starts as |
|---|---|---|
| **+ Number** | `progress` | `0.35` |
| **+ Text** | `label` | `Uploading` |
| **+ Color** | `color` | `#7c5cff` |

## Step 5: bindings

1. Select `ring` → **Add Component → Events & Data → Property Binding** → **+ Bind a property**: `progress` → under **Components**, `StrokeStyle2D › trimEnd`. Leave × `1`, + `0`.
2. Select `caption` → Property Binding: `label` → **Text**, format `{}`.
3. Select `percent` → Property Binding: `color` → **Fill colour**.

Now, with nothing but bindings, changing `progress` fills the ring, changing `label` changes the caption, and `color` tints the percentage. (A Shape's stroke colour isn't a binding target; the arc keeps the colour you gave it.)

## Step 6: the state machine

1. **Timeline** → animation dropdown → **New Animation** (needed once per scene).
2. **State Machine** → **New State Machine** `Progress`. It has `State 1` (initial). **+ Add State** adds `State 2`.
3. **Inputs**: declare `complete` as **Bool**.
4. Transition `State 1` → `State 2` with **Boolean is** `complete`, required value true; `State 2` → `State 1` with **Boolean is** `complete`, false.
5. Tick **Programmable State** on both states. In **Code** mode create `Scripts/ring.js` (**+js**), paste the script below, and set both states' **Runs** to it.

:::note State names
The finished `progress-ring.teab` calls its states `Loading` and `Done` and keeps its internal logic to itself. The editor names new states `State 1`, `State 2`, … with no rename in the panel, so in your build `State 1` is Loading and `State 2` is Done. The page-facing contract (Properties `progress`, `label`, `color`, the `done` event) is the same.
:::

## Step 7: the script

```js title="Scripts/ring.js"
// =====================================================================
// Progress ring. Runs in both states ("State 1" = Loading,
// "State 2" = Done). Bindings already draw the arc, caption and colour;
// this adds what bindings can't: the percentage text, the state, the
// "done" event and a little celebration.
// =====================================================================
const LOADING = 'State 1'
const DONE = 'State 2'

const G = ctx.globals
// Properties are already numbers, but clamp: pages send odd values.
const p = clamp(Number(ctx.props.progress) || 0, 0, 1)

// 1. The percentage (a Text binding can't multiply by 100 and round).
const percent = getCompByID('percent')
const text = Math.round(p * 100) + '%'
if (percent && percent.textContent !== text) percent.textContent = text

// 2. The state follows the data. Setting a Bool input to the value it
//    already has does nothing, so this is safe every frame.
ctx.setInput('complete', p >= 1)

// 3. Tell the page once per completion. Re-arm when it goes back to Loading
//    (a new upload).
if (ctx.state === DONE) {
  if (!G.doneSent) {
    G.doneSent = true
    ctx.emit('done', {})
  }
} else {
  G.doneSent = false
}

// 4. Looks. ctx.time = seconds since this state was entered.
const ring = getCompByID('ring')
const check = getCompByID('check')
let scale = 1
if (ctx.state === DONE && ctx.time < 0.4) {
  scale = 1 + Math.sin((ctx.time / 0.4) * Math.PI) * 0.12   // a quick "pop" on finishing
}
scale = Math.round(scale * 1000) / 1000
if (ring && ring.scaleY !== scale) {
  // Keep Scale X's sign (it may be -1 to fill clockwise).
  ring.scaleX = Math.sign(ring.scaleX || 1) * scale
  ring.scaleY = scale
}
const showCheck = ctx.state === DONE
if (check && check.visible !== showCheck) check.visible = showCheck
if (percent && percent.visible === showCheck) percent.visible = !showCheck
```

## How it works

- **Bindings do the drawing.** `progress` drives the stroke's trim directly; the script never touches the arc. If you deleted the script, the ring would still fill.
- **`ctx.setInput('complete', p >= 1)`** turns a value into a state. The transition with **Boolean is** then moves to Done, and back if a new upload resets `progress`. This is the general recipe for "data decides the state": compute a Bool (or Number / Enum) from Properties and set an input.
- **`ctx.emit('done', {})`** fires once per completion thanks to `G.doneSent`, a flag in `ctx.globals` re-armed whenever the ring is loading again.
- **The pop** uses `ctx.time`, which restarts at 0 when Done is entered.

## Check your work

In **Playground**:

- With nothing selected, the Properties' values are the starting ones; change `progress`'s **Starts as** to `0.8` and replay: the arc is at 80 % and the text reads `80%`.
- Set it to `1` and replay: the ring pops, the tick replaces the percentage, and the Console shows `ctx.emit("done", {})`.
- Set it back to `0.35`.
