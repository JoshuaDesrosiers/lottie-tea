# 5. A notification bell

**Goal:** a bell that shows how many notifications are unread, rings when a new one arrives, and opens a list when clicked.

**What you'll learn**

- The difference between **data** (a value: `unread`) and a **trigger** (a moment: `ring`).
- Getting the player handle with `onReady` to call `fire`.
- Handling a scene event (`open`) to drive page UI.
- Reacting to the bell's states.

## The bell's contract

| Kind | Name | Notes |
|---|---|---|
| Property | `unread` (Number, default `3`) | The badge count. |
| Trigger | `ring` | Plays the ringing animation. |
| States | `Quiet`, `Ringing` | The base layer. |
| Event | `open` `{ unread }` | Sent when the bell is clicked. |

## Values versus moments

"There are 4 unread notifications" is a **value**: send it as data, as often as you like, and nothing happens unless it changes. "A notification just arrived" is a **moment**: you want the bell to ring *every* time, even if two arrive with the count going 4 → 5 → 4 (one read, one new). Moments are triggers:

```ts
player.fire('ring')
```

React can also set inputs declaratively (`inputs={{ ring: true }}`), but a Trigger in `inputs` only fires when its value *changes* to truthy, so for repeated rings call `fire` on the player handle.

## The code

```tsx title="src/NotificationBell.tsx"
import { useEffect, useRef, useState } from 'react'
import { An1Player, type An1PlayerHandle } from './an1mbyt3/an1mbyt3-react.js'

interface Note {
  id: string
  text: string
  read: boolean
}

export function NotificationBell({ feedUrl }: { feedUrl: string }) {
  const [notes, setNotes] = useState<Note[]>([])
  const [open, setOpen] = useState(false)
  const player = useRef<An1PlayerHandle | null>(null)
  const unread = notes.filter((n) => !n.read).length

  // A server-sent event stream of new notifications (any push channel works).
  useEffect(() => {
    const source = new EventSource(feedUrl)
    source.onmessage = (e) => {
      const note = JSON.parse(e.data) as Note
      setNotes((list) => [note, ...list])
      player.current?.fire('ring') // a moment: ring once per new note
    }
    return () => source.close()
  }, [feedUrl])

  return (
    <div style={{ position: 'relative', width: 96 }}>
      <An1Player
        game="/an1mbyt3/game.teab"
        style={{ width: 96, height: 96 }}
        data={{ unread }}                       // a value: the badge
        onReady={(p) => (player.current = p)}   // works on React 18 and 19
        onEvent={(e) => {
          if (e.name === 'open') setOpen((o) => !o)
        }}
      />
      {open && (
        <ul role="menu" style={{ position: 'absolute', top: 96, right: 0, width: 280 }}>
          {notes.length === 0 && <li>No notifications</li>}
          {notes.map((n) => (
            <li key={n.id} style={{ fontWeight: n.read ? 400 : 700 }}>{n.text}</li>
          ))}
          <li>
            <button onClick={() => setNotes((list) => list.map((n) => ({ ...n, read: true })))}>Mark all read</button>
          </li>
        </ul>
      )}
    </div>
  )
}
```

## Try it live

Here a timer stands in for the server: a "new notification" arrives every few seconds. Click the bell to open the list.

```jsx live
function BellDemo() {
  const [notes, setNotes] = React.useState([
    { id: 1, text: 'Ada commented on your post', read: false },
    { id: 2, text: 'Your export finished', read: false },
    { id: 3, text: 'Weekly report is ready', read: false },
  ])
  const [open, setOpen] = React.useState(false)
  const [auto, setAuto] = React.useState(true)
  const player = React.useRef(null)
  const unread = notes.filter((n) => !n.read).length

  const arrive = () => {
    const texts = ['Grace liked your scene', 'New follower: Linus', 'Build #42 passed', 'Margaret mentioned you']
    setNotes((list) => [{ id: Date.now(), text: texts[Math.floor(Math.random() * texts.length)], read: false }, ...list].slice(0, 8))
    player.current?.fire('ring')
  }

  React.useEffect(() => {
    if (!auto) return
    const t = setInterval(arrive, 6000)
    return () => clearInterval(t)
  }, [auto])

  return (
    <div style={{ display: 'flex', gap: 24, alignItems: 'flex-start' }}>
      <ToastyPlayer
        game="/games/bell.teab"
        style={{ width: 140, height: 140 }}
        data={{ unread }}
        onReady={(p) => (player.current = p)}
        onEvent={(e) => e.name === 'open' && setOpen((o) => !o)}
      />
      <div>
        <button onClick={arrive}>New notification now</button>{' '}
        <label><input type="checkbox" checked={auto} onChange={(e) => setAuto(e.target.checked)} /> one every 6 s</label>
        {open && (
          <ul>
            {notes.map((n) => <li key={n.id} style={{ fontWeight: n.read ? 400 : 700 }}>{n.text}</li>)}
            <li><button onClick={() => setNotes((l) => l.map((n) => ({ ...n, read: true })))}>Mark all read</button></li>
          </ul>
        )}
      </div>
    </div>
  )
}
```

## How it works

- **`unread` is derived**, never stored separately: `notes.filter((n) => !n.read).length`. Marking all read sets every note's `read`, the count becomes `0`, and the badge updates through `data`.
- **`fire('ring')`** goes to the bell's state machine; its transition on the `ring` trigger plays `Ringing`.
- **`onReady`** hands you the player once it's running. Keep it in a ref and call it from timers and event handlers. (On React 19 you can also pass `ref` straight to `An1Player`.)
- **`open`** is the bell's own event, sent when it's clicked, with the unread count in its payload. The page decides what opening means.

:::tip Ringing and accessibility
A ringing bell catches the eye but not a screen reader. Mirror it in the DOM: an `aria-live="polite"` region that says "New notification: …" when one arrives, and a real `<button aria-label="Notifications, 4 unread">` for keyboard users, the same approach as the [like button's accessible control](../react-like-button/06-events-and-polish.mdx).
:::

## Check your work

- Clicking **New notification now** rings the bell and the badge goes up by one.
- Clicking the bell opens the list; **Mark all read** clears the badge.
- With the auto checkbox on, the bell rings on its own every six seconds.
