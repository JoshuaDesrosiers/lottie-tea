# 3. Ground, physics and jumping

**Goal:** the ninja runs with the arrow keys or A/D and jumps with Space, landing on solid platforms.

**What you'll learn**

- Painting ground with a **Tilemap** and the **Tile Palette**.
- Static scenery with **Box Collider 2D** (no Rigidbody 2D needed).
- A player body: **Rigidbody 2D** with **Freeze Rotation** and a **Capsule Collider 2D**.
- Driving a physics body with `ref.velocity`.
- Ground checks with `ctx.raycast`.
- Game-feel tricks: acceleration, coyote time, a jump buffer and variable jump height.

## Step 1: paint the ground

1. **+** → **2D Object** → **Tilemap…**. Pick your tileset image. Answer the two prompts with the tile width and height: `16` and `16`.
2. With the new Tilemap selected, set its Inspector fields:
   - **Cell Size** `16`, so one tile is 16 world units (one art pixel = one unit, like the camera).
   - **Map Size** **w** `60`, **h** `17`: a level two screens wide.
3. Open the **Tile Palette** (left icon rail), click a grass-topped tile, and click and drag on the canvas to paint a floor along the bottom of the view. Add a couple of raised ledges and a gap to jump.

Tiles are only pictures. The ninja would fall straight through them: solidity comes from colliders.

## Step 2: solid platforms

Make one invisible block per platform:

1. **+** → **2D Object** → **Rectangle**. It's 120 × 120.
2. **Add Component** → **Physics 2D** → **Box Collider 2D**. Set its **Size** to **X** `120`, **Y** `120` so it matches the rectangle.
3. Now stretch the rectangle with **Scale** (the collider scales with it) and move it over a painted platform. For a floor 960 wide and 48 tall: **Scale X** `8`, **Scale Y** `0.4`.
4. Make its fill fully transparent so only the tiles show. The editor still draws the collider's outline while you work.
5. Repeat for each ledge (copy with **Ctrl+C**, paste in place with **Ctrl+V**, then move and scale).

A collider with no Rigidbody 2D on it (or its parents) is **static scenery**: it never moves, and dynamic bodies collide with it. That's exactly what ground is. The built-in Physics Playground demo builds its floor, walls and ledges the same way.

## Step 3: the player's body

Select `player` and add two components:

1. **Add Component** → **Physics 2D** → **Rigidbody 2D**.
   - **Body Type**: `Dynamic`.
   - **Mass**: `1`.
   - **Gravity Scale**: `1`.
   - **Collision**: `Continuous` (a fast fall can't tunnel through thin ledges).
   - Under **Constraints**, tick **Freeze Rotation**. Without it the ninja would tip over like a crate.
2. **Add Component** → **Physics 2D** → **Capsule Collider 2D**.
   - **Size**: **X** `14`, **Y** `24` for 32-pixel cells (half that for 16-pixel cells). Narrower than the sprite, so the ninja can stand near edges.
   - **Offset**: **Y** `-4`, to sit at the feet rather than the middle of the cell.
   - **Direction**: `Vertical`.
   - **Friction** `0`. With friction, the ninja would stick to walls when you jump into them.

A capsule's round bottom slides over the seams between blocks instead of catching on them.

## Step 4: the movement script

Replace `Scripts/ninja.js` with:

```js title="Scripts/ninja.js (lesson 3)"
// =====================================================================
// Ninja platformer - lesson 3: running and jumping.
// Runs every frame in every level scene (State 1, Runs: Scripts/ninja.js).
// =====================================================================

// ---- Tuning ----------------------------------------------------------
const RUN_SPEED = 110     // world units per second at full run
const ACCEL = 14          // how quickly we reach RUN_SPEED (bigger = snappier)
const JUMP_SPEED = 250    // upward velocity at take-off (about 6 tiles high)
const JUMP_CUT = 0.45     // let go of jump early: keep only this much upward speed
const COYOTE_TIME = 0.1   // seconds you can still jump after running off a ledge
const JUMP_BUFFER = 0.12  // seconds a too-early jump press is remembered
const FEET_RAY = 20       // ray length from the body's centre to just below the feet
const FEET_SPREAD = 5     // two rays, this far left and right of centre

const G = ctx.globals
// Clamp the frame time: after a hitch, one huge step would launch the ninja.
const dt = Math.min(ctx.deltaSeconds, 1 / 20)
const keys = ctx.keysDown
const player = getCompByID('player')
if (!player) return

// player.velocity is null when the node has no simulated body (or when
// the script runs outside Playground). Nothing to do then.
const v = player.velocity
if (!v) return

// ---- Ground check ------------------------------------------------------
// Two short rays straight down from the body's centre. The last argument
// tells the ray to ignore the player's own collider.
const onGround = [-FEET_SPREAD, FEET_SPREAD].some(
  (dx) => ctx.raycast(player.x + dx, player.y, 0, -1, FEET_RAY, player) !== null,
)
// Rising fast means we just jumped, even if the rays still touch the floor.
const grounded = onGround && v.y <= 1

// ---- Run ---------------------------------------------------------------
const dir = (keys.has('right') || keys.has('d') ? 1 : 0) - (keys.has('left') || keys.has('a') ? 1 : 0)
if (dir !== 0) G.facing = dir < 0 ? 'left' : 'right'
// Ease the horizontal speed toward the target instead of snapping to it.
const k = Math.min(1, dt * ACCEL)
let vx = v.x + (dir * RUN_SPEED - v.x) * k
let vy = v.y

// ---- Jump ----------------------------------------------------------------
const jumpDown = keys.has('space') || keys.has('w') || keys.has('up')
const jumpPressed = jumpDown && !G.jumpHeld          // true on the press frame only
if (jumpPressed) G.jumpBuffer = JUMP_BUFFER
G.jumpBuffer = (G.jumpBuffer || 0) - dt
G.coyote = grounded ? COYOTE_TIME : (G.coyote || 0) - dt

if (G.jumpBuffer > 0 && G.coyote > 0) {
  vy = JUMP_SPEED
  G.jumpBuffer = 0
  G.coyote = 0
  // A quick upward chirp, synthesized: no sound file needed.
  ctx.playTone({ freq: 220, to: 520, type: 'square', duration: 0.12, volume: 0.12 })
}
// Variable height: releasing jump while still rising cuts the jump short.
if (!jumpDown && G.jumpHeld && vy > 0) vy *= JUMP_CUT
G.jumpHeld = jumpDown

// ---- Apply ---------------------------------------------------------------
player.velocity = { x: vx, y: vy }
```

Press **Playground**, click the canvas so it has keyboard focus, and run and jump.

## How it works

### Steering a physics body

Physics owns the ninja's position: gravity pulls it, colliders stop it. The script never writes `player.x`; it reads `player.velocity` (world units per second, **+y up**) and writes a new one. Horizontal speed is eased toward `dir * RUN_SPEED`, which gives a tiny bit of acceleration and slide. Vertical speed is left to gravity except at the moment of a jump. This is the Physics Playground demo's approach:

```js
// From the Physics Playground demo.
const v = player.velocity
const k = Math.min(1, ctx.deltaSeconds * 12)
player.velocity = { x: v.x + (dir * 170 - v.x) * k, y: v.y }
```

The demo jumps with `player.addImpulse(0, 340)`. Setting `vy` directly, as here, gives the same height whatever the body's mass is.

### Raycasts for the ground

`ctx.raycast(x, y, dirX, dirY, maxDistance, ignore)` returns the first non-trigger collider along the ray, or `null`. Two rays at the feet's left and right edges mean the ninja can still jump while half off a ledge. The last argument, `player`, stops the ray hitting the ninja's own capsule. See [Physics API](../../scripting/physics-api.mdx).

### Edges: "pressed this frame"

`ctx.keysDown` is a set of keys held *right now* (`'space'`, `'left'`, `'a'`…). A jump should fire once per press, not every frame while held, so the script remembers last frame's state in `G.jumpHeld` and reacts only when it changes from up to down. Ninja Adventure uses the same `spacePrev` trick. See [Input](../../scripting/input.mdx).

### Coyote time and the jump buffer

Two forgiving timers that players feel but never notice:

- **Coyote time**: `G.coyote` refills while grounded and drains in the air, so a jump pressed 0.1 s after running off an edge still works.
- **Jump buffer**: a press is remembered for 0.12 s, so pressing jump just *before* landing jumps on landing.

A jump happens when both timers are positive, and spends both.

### Variable jump height

When you let go of jump while still going up, `vy *= JUMP_CUT` slows the climb: tap for a hop, hold for a full jump.

## Check your work

- The ninja falls onto the floor and stands on it (it doesn't sink in, slide, or tip over).
- Arrow keys / A and D run; Space, W or Up jump with a chirp. Tapping gives a short hop, holding a full jump.
- Running off a ledge and pressing jump a moment late still jumps.
- Jumping into a wall doesn't stick.

If the ninja falls through the floor, check that the floor rectangle has a **Box Collider 2D** whose outline covers the tiles. If it can't jump, the rays may be too short: increase `FEET_RAY` until a `print(onGround)` shows `true` when standing.
