# 7. Export to the web

**Goal:** your platformer playable by anyone with a browser, as a standalone page or inside your own site.

**What you'll learn**

- **Export → Game → Web page (.html)**: one file, runs anywhere.
- **Export → Game → Website embed (React / JS)**: a folder for your web project.
- Starting on the right scene, keyboard focus, and listening for `won`.

## Before exporting

- Open `Level 1` so it's the active scene. Both exports start on the active scene.
- Play through once more in Playground and check the Console for errors.
- Save the project.

## Option A: a web page

1. **Export** (toolbar) → **Game → Web page (.html)**.
2. Save the file, for example `ninja.html`.

That's the whole game, engine included, in one page. Open it in a browser, or upload it to any static host (GitHub Pages, Netlify, itch.io as an HTML game, your own server). Nothing else to install. See [Exporting](../../editor/exporting.mdx).

## Option B: inside your site

**Export → Game → Website embed (React / JS)** writes a folder with the engine, the game file and ready-made JavaScript. Copy `src/an1mbyt3/` into your source folder and `public/an1mbyt3/` into your static folder, exactly as in the [like button course](../react-like-button/04-export-and-embed.mdx), then:

```tsx title="src/NinjaGame.tsx"
import { useState } from 'react'
import { An1Player } from './an1mbyt3/an1mbyt3-react.js'

export function NinjaGame() {
  const [result, setResult] = useState<number | null>(null)

  return (
    <section>
      <An1Player
        game="/an1mbyt3/game.teab"
        scene="Level 1"
        // 16:9 like the scene, so there are no letterbox bars.
        style={{ width: '100%', aspectRatio: '16 / 9' }}
        // Keys reach the game while it has focus (click it first). Use
        // 'window' for a full-page game that should hear keys anywhere.
        keyboard="focus"
        onEvent={(e) => {
          // From the script: ctx.emit('won', { score: G.score })
          if (e.name === 'won') setResult((e.payload as { score: number }).score)
        }}
        onSceneChange={(e) => console.log('now playing', e.scene)}
      />
      {result !== null && (
        <p>
          You won with {result} points! <a href="/leaderboard">Post your score</a>
        </p>
      )}
    </section>
  )
}
```

The plain-JavaScript equivalent:

```html title="ninja.html (embed version)"
<div id="game" style="width: 100%; aspect-ratio: 16 / 9"></div>
<p id="result"></p>
<script type="module">
  import { createPlayer } from './src/an1mbyt3/an1mbyt3-embed.js'

  const player = await createPlayer(document.getElementById('game'), {
    game: './public/an1mbyt3/game.teab',
    scene: 'Level 1',
    keyboard: 'focus',
  })
  player.on('event', ({ name, payload }) => {
    if (name === 'won') document.getElementById('result').textContent = `You won with ${payload.score} points!`
  })
</script>
```

Serve the folder over HTTP (`npx serve .`): browsers refuse to load the engine from `file://`.

## How it works

- **`scene`** picks the starting scene by name (the default is the first scene). In React it's live: changing it switches scenes.
- **`keyboard`**: `'focus'` (the default) only sends keys while the game is focused, so arrow keys still scroll the rest of your page. `'window'` sends every key to the game. `'none'` sends none.
- **Events**: everything a script `ctx.emit`s arrives in `onEvent` (React) or `player.on('event', …)`. Scene switches made by `ctx.loadScene` arrive in `onSceneChange` / `player.on('scene', …)`.
- **Letterboxing**: the game fits inside its box like a video. A box with the scene's aspect ratio (16:9 here) has no bars; `fit="cover"` fills the box and crops instead.

More in [Embedding on the web](../../embedding/overview.mdx).

## Check your work

- `ninja.html` opens in a browser and plays from Level 1 through the win screen.
- In your site, the game appears at full width, plays after one click, and the "You won" line appears when you reach the last door.

## Where to go next

You've used the core of Toasty game-making: sprites, physics, a frame-by-frame script, Properties and bindings, particles, sound, scenes and export. Ideas for taking the platformer further:

- **Enemies**: Ninja Adventure's enemy code (roam → approach → windup → strike → recover) is a great model for a patrolling slime. Read it in the demo (**+ → Demos → Ninja Adventure**, then **Code** mode → **Scene scripts**).
- **Saving progress**: `ctx.storage.set('ninja', { best: G.score })` survives reloads. See [Storage API](../../scripting/storage-api.mdx); the [Crown Match course](../match3/07-levels-scoring-and-saving.mdx) uses it for unlocked levels.
- **Recorded sounds**: import audio and use `ctx.playSound`. See [Audio](../../components/audio.mdx).
- **Lighting**: a Light 2D on the ninja for a lantern glow, as in Ninja Adventure. See [Lighting 2D](../../components/lighting-2d.mdx).
