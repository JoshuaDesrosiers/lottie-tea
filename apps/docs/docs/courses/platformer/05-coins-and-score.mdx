# 5. Coins, score and sound

**Goal:** coins spin, vanish with a sparkle and a "bling" when touched, and a score display counts them, with no code touching the display.

**What you'll learn**

- Finding many nodes at once with **Classes** and `getCompByClass`.
- A simple pickup test, and remembering collected items across scene visits.
- Scene **Properties** plus a **Property Binding** for the HUD.
- A one-shot **Particle System** moved to the action with `ref.emit(n)`.
- Sound effects with `ctx.playTone`.

## Step 1: more coins

1. Select the coin from lesson 2 (class `coin`).
2. **Ctrl+C**, then **Ctrl+V** pastes a copy in place. Drag it somewhere else. Repeat for 8–10 coins: along the floor, over gaps, on ledges.

Copies keep the `coin` class and get their own unique Id each, which is all the script needs.

## Step 2: the HUD

1. **+** → **2D Object** → **Text**. Set its text to `SCORE 0`, a size around `12`, and a light colour. If you like the pixel look, pick **Press Start 2P** as its font.
2. In **Layers**, drag the text onto the `camera` row (drop on the lower half of the row) to make it the camera's child. Children of the camera move with it, so the HUD stays put on screen.
3. Set its position relative to the camera to the top-left area, around **X** `-170`, **Y** `120`.
4. Add a second text the same way for coins remaining: `COINS 0`, around **X** `150`, **Y** `120`.

Now the Properties:

1. Click empty canvas (nothing selected). Under **Properties**, click **+ Number** twice and rename them to `score` and `coinsLeft`, both starting at `0`.
2. Select the score text → **Add Component** → **Events & Data** → **Property Binding** → **+ Bind a property**: `score` → **Text**, format `SCORE {}`.
3. Select the coins text and bind `coinsLeft` → **Text**, format `COINS {}`.

<Shot id="platformer-hud-binding" caption="The score text's Property Binding: score -> Text with the format SCORE {}." />

## Step 3: a sparkle burst

1. **+** → **Effects** → **Particle System**. Set its **Id** to `sparkle`.
2. Untick **Looping**. Set **Emission → Rate/sec** to `0`.
3. **Lifetime** about `0.2`–`0.5`, **Speed** `20`–`70`, **Size** `1`–`3`, **Color** gold (`#ffd94a`), **Gravity** a little positive so sparks fall.

The script will move it to each coin and fire it.

## Step 4: the script

Replace `Scripts/ninja.js`. New parts are marked **NEW**.

```js title="Scripts/ninja.js (lesson 5)"
// =====================================================================
// Ninja platformer - lesson 5: + coins, score and sound.
// =====================================================================

// ---- Tuning ----------------------------------------------------------
const RUN_SPEED = 110
const ACCEL = 14
const JUMP_SPEED = 250
const JUMP_CUT = 0.45
const COYOTE_TIME = 0.1
const JUMP_BUFFER = 0.12
const FEET_RAY = 20
const FEET_SPREAD = 5
const WALK_FPS = 8
const IDLE_FPS = 4
const LOOK_AHEAD = 30
const PICKUP_X = 12         // NEW: how close (horizontally) counts as touching a coin
const PICKUP_Y = 16         // NEW: ...and vertically
const COIN_POINTS = 10      // NEW

const LEVELS = {
  'Level 1': { camera: [0, 0, 480, 0] },
}

const G = ctx.globals
const level = LEVELS[ctx.scene]
const dt = Math.min(ctx.deltaSeconds, 1 / 20)
const keys = ctx.keysDown
const player = getCompByID('player')
if (!level || !player) return

// ---- Once per play session -----------------------------------------------
if (!G.started) {
  G.started = true
  G.frames = {}
  for (const img of ctx.images) G.frames[img.name] = img.id
  G.score = 0              // NEW: the score lives here, not in a Property (see below)
  G.collected = {}         // NEW: "Level 1:shape(14)" -> true
}

// ---- Once per scene entry --------------------------------------------------
if (G.sceneName !== ctx.scene) {
  G.sceneName = ctx.scene
  G.facing = 'right'
  G.clock = 0
  G.camX = null
  G.frameOf = {}
  G.jumpHeld = false
  G.jumpBuffer = 0
  G.coyote = 0
}
G.clock += dt

function setFrame(ref, name) {
  if (G.frameOf[ref.id] === name) return
  const id = G.frames[name]
  if (!id) return
  G.frameOf[ref.id] = name
  ref.image = id
}

// NEW: a particle burst at (x, y): move the emitter there, then emit.
function burst(id, x, y, count) {
  const fx = getCompByID(id)
  if (!fx) return
  fx.x = x
  fx.y = y
  fx.emit(count)
}

const v = player.velocity
if (!v) return

// ---- Ground check --------------------------------------------------------------
const onGround = [-FEET_SPREAD, FEET_SPREAD].some(
  (dx) => ctx.raycast(player.x + dx, player.y, 0, -1, FEET_RAY, player) !== null,
)
const grounded = onGround && v.y <= 1

// ---- Run ---------------------------------------------------------------------------
const dir = (keys.has('right') || keys.has('d') ? 1 : 0) - (keys.has('left') || keys.has('a') ? 1 : 0)
if (dir !== 0) G.facing = dir < 0 ? 'left' : 'right'
const k = Math.min(1, dt * ACCEL)
let vx = v.x + (dir * RUN_SPEED - v.x) * k
let vy = v.y

// ---- Jump ------------------------------------------------------------------------
const jumpDown = keys.has('space') || keys.has('w') || keys.has('up')
if (jumpDown && !G.jumpHeld) G.jumpBuffer = JUMP_BUFFER
G.jumpBuffer -= dt
G.coyote = grounded ? COYOTE_TIME : G.coyote - dt
if (G.jumpBuffer > 0 && G.coyote > 0) {
  vy = JUMP_SPEED
  G.jumpBuffer = 0
  G.coyote = 0
  ctx.playTone({ freq: 220, to: 520, type: 'square', duration: 0.12, volume: 0.12 })
}
if (!jumpDown && G.jumpHeld && vy > 0) vy *= JUMP_CUT
G.jumpHeld = jumpDown
player.velocity = { x: vx, y: vy }

// ---- Animation -----------------------------------------------------------------
const col = G.facing === 'left' ? 2 : 3
let frame
if (!grounded) frame = 'ninja_walk ' + (1 * 4 + col)
else if (Math.abs(vx) > 10) frame = 'ninja_walk ' + ((Math.floor(G.clock * WALK_FPS) % 4) * 4 + col)
else frame = 'ninja_idle ' + ((Math.floor(G.clock * IDLE_FPS) % 4) * 4 + col)
setFrame(player, frame)

// ---- NEW: coins -------------------------------------------------------------------
let coinsLeft = 0
for (const coin of getCompByClass('coin')) {
  // Ids are unique within a scene; add the scene name so two levels'
  // coins can never be confused.
  const key = ctx.scene + ':' + coin.id
  if (G.collected[key]) {
    // Re-hide on every visit: entering a scene restores its designed nodes.
    if (coin.visible) coin.visible = false
    continue
  }
  coinsLeft++
  // Spin: 8 frames a second, each coin offset by its position so they
  // don't all turn in lockstep.
  setFrame(coin, 'coin ' + (Math.floor(G.clock * 8 + Math.abs(coin.x) * 0.05) % 4))
  // Touching? (Player's origin is its body centre; coins are small.)
  if (Math.abs(coin.x - player.x) < PICKUP_X && Math.abs(coin.y - player.y) < PICKUP_Y) {
    G.collected[key] = true
    coin.visible = false
    coinsLeft--
    G.score += COIN_POINTS
    burst('sparkle', coin.x, coin.y, 12)
    // "Bling": a short square-wave slide up a fifth.
    ctx.playTone({ freq: 988, to: 1480, type: 'square', duration: 0.09, volume: 0.15 })
  }
}

// ---- NEW: HUD (through Properties; Property Bindings draw the text) ------------
ctx.props.score = G.score
ctx.props.coinsLeft = coinsLeft

// ---- Camera ---------------------------------------------------------------------
const cam = getCompByID('camera')
if (cam) {
  const b = level.camera
  const tx = clamp(player.x + (G.facing === 'left' ? -LOOK_AHEAD : LOOK_AHEAD), b[0], b[2])
  const ty = clamp(player.y + 20, b[1], b[3])
  if (G.camX === null) {
    G.camX = tx
    G.camY = ty
  }
  const t = 1 - Math.exp(-8 * dt)
  G.camX += (tx - G.camX) * t
  G.camY += (ty - G.camY) * t
  cam.x = Math.round(G.camX)
  cam.y = Math.round(G.camY)
}
```

## How it works

### Classes find groups of nodes

`getCompByClass('coin')` returns a ref for every node carrying the `coin` class, like `document.getElementsByClassName`. Add a coin in the editor and the script picks it up, no code changes. See [Nodes and refs](../../scripting/nodes-and-refs.mdx).

### Picking up

The test is a box around the player: close enough in X and in Y. It's the same check Ninja Adventure uses for its pickups (`PICKUP_RADIUS_X`, `PICKUP_RADIUS_Y`). You could instead give each coin a **Circle Collider 2D** with **Is Trigger** ticked and read `ctx.collisions` (the Physics Playground's goal box works that way), but for many small pickups a distance check is simpler and cheaper.

Collected coins are hidden with `coin.visible = false` and remembered in `G.collected`. Hiding a node with a script doesn't change your design: leaving Playground brings every coin back.

### Why the score lives in `ctx.globals`

Scene Properties reset to their starting values every time a scene is entered. That's right for the HUD's *display*, but wrong for a score that must survive moving to level 2. So the real score lives in `G.score` (globals survive scene switches) and the script copies it into `ctx.props.score` every frame. Writing a Property the value it already has changes nothing and costs almost nothing, and when it does change, the Property Binding redraws the text.

### Sparkles and sound

`burst` is lifted from Ninja Adventure: move a non-looping Particle System to the spot, then `emit(count)`. The particles appear next frame where the emitter now is.

`ctx.playTone` synthesizes the bling: a square wave sliding from 988 Hz to 1480 Hz over 0.09 s. Options are `freq`, `to`, `type` (`'square'`, `'sine'`, `'sawtooth'`, `'triangle'`, `'noise'`), `duration`, `volume`, `attack`, `release` and `pan`. For recorded sounds, import audio with **+ → Import → Audio…** and use `ctx.playSound('coin')`. See [Audio API](../../scripting/audio-api.mdx).

:::note Ninja Adventure's sound
The demo builds its blips with the browser's Web Audio API directly (its `blip()` helper). `ctx.playTone` does the same job in one line, through the same audio engine as every other game sound.
:::

## Check your work

- Coins spin out of sync with each other.
- Touching a coin: it disappears with gold sparks and a bling; SCORE goes up by 10 and COINS down by 1.
- The HUD stays in the corner as the camera moves.
- Stop and start Playground: every coin is back and the score is 0.
