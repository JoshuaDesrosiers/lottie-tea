# 6. A second level

**Goal:** a door at the end of Level 1 takes you to Level 2, the score carries over, falling off the level puts you back at the start, and Level 2's door wins the game.

**What you'll learn**

- **Prefabs**: build once, place in any scene.
- A new scene, wired to the same script.
- `ctx.loadScene` and why it's deferred to the end of the frame.
- What survives a scene switch (`ctx.globals`) and what doesn't (nodes, Properties).
- Teleporting a physics body.
- `ctx.emit` for when the game is embedded.

## Step 1: prefabs for the reusable parts

1. In Level 1, select `player`. In the Inspector, click **Create Prefab**. The ninja (with its Rigidbody 2D and capsule) is now a prefab in **Resources → Prefabs**.
2. Do the same for one coin and for `sparkle`.

See [Prefabs](../../editor/prefabs.mdx) for everything prefabs can do.

## Step 2: a door in Level 1

1. Place something door-like at the far right of Level 1: a door tile from a house tileset dragged in from Resources, or a tall **Rectangle** with a dark fill.
2. Set its **Id** to `door`. No collider: the script checks distance, so the ninja walks *into* the doorway.

## Step 3: build Level 2

1. Open the **Scene** dropdown → **+ New Scene**, name it `Level 2` (exactly).
2. Canvas: **Size** `480` × `270`, default gravity.
3. **Camera**: **+ → Camera**, Id `camera`, tick **Main Camera** and **Pixel Perfect**, same background.
4. **Ground**: a Tilemap (Cell Size `16`) and Box Collider 2D rectangles, as in [lesson 3](./03-ground-and-physics.mdx). Make it a bit harder: wider gaps, higher ledges.
5. **Player**: drag the player prefab from **Resources → Prefabs** onto the left of the level. Prefab copies get a fresh Id, so **set its Id back to `player`**.
6. **Coins**: drag the coin prefab in a few times (copies keep the `coin` class).
7. **Sparkle**: drag the sparkle prefab in and set its **Id** back to `sparkle`.
8. **HUD**: the two Properties `score` and `coinsLeft` (Number, `0`), two texts parented to the camera with Property Bindings, as in [lesson 5](./05-coins-and-score.mdx).
9. **Win banner**: one more text, parented to the camera at **X** `0`, **Y** `20`, size `16`, with an empty text. **Id** `banner`.
10. **Exit**: a door at the far right, **Id** `door`.
11. **State machine**: **Timeline → New Animation**, then **State Machine → New State Machine** (`Game`), tick **Programmable State** on `State 1`, double-click it, **Code** tab, **Runs** → `Scripts/ninja.js`.

## Step 4: the finished script

Replace `Scripts/ninja.js` with the complete game. New parts are marked **NEW**.

```js title="Scripts/ninja.js (final)"
// =====================================================================
// Ninja platformer - the complete game. One script, run by every level
// scene (State 1 of each scene's "Game" state machine).
//
// What lives where:
//   ctx.globals (G)  - survives scene switches: score, collected coins.
//   scene nodes      - reset to their designed state on every scene entry.
//   ctx.props        - this scene's Properties (also reset on entry); the
//                      HUD reads them through Property Bindings.
// =====================================================================

// ---- Tuning ----------------------------------------------------------
const RUN_SPEED = 110       // world units per second at full run
const ACCEL = 14            // how quickly we reach RUN_SPEED
const JUMP_SPEED = 250      // upward velocity at take-off
const JUMP_CUT = 0.45       // releasing jump early keeps this much upward speed
const COYOTE_TIME = 0.1     // late-jump grace after leaving a ledge (s)
const JUMP_BUFFER = 0.12    // early-jump grace before landing (s)
const FEET_RAY = 20         // ground ray length from the body's centre
const FEET_SPREAD = 5       // the two ground rays' offset from centre
const WALK_FPS = 8
const IDLE_FPS = 4
const LOOK_AHEAD = 30       // camera lead in the facing direction
const PICKUP_X = 12
const PICKUP_Y = 16
const COIN_POINTS = 10
const DOOR_X = 12           // NEW: how close to the door's centre counts as "in"
const DOOR_Y = 24

// ---- Per-level data, keyed by scene name -------------------------------------
// camera: [minX, minY, maxX, maxY] for the camera's centre.
// fallY:  below this height the ninja has fallen off the level.
// next:   the scene the door leads to; null = this door wins the game.
const LEVELS = {
  'Level 1': { camera: [0, 0, 480, 0], fallY: -220, next: 'Level 2' },
  'Level 2': { camera: [0, 0, 960, 120], fallY: -220, next: null },
}

const G = ctx.globals
const level = LEVELS[ctx.scene]
const dt = Math.min(ctx.deltaSeconds, 1 / 20)
const keys = ctx.keysDown
const player = getCompByID('player')
if (!level || !player) return

// ---- Once per play session -----------------------------------------------------
if (!G.started) {
  G.started = true
  G.frames = {}
  for (const img of ctx.images) G.frames[img.name] = img.id
  G.score = 0
  G.collected = {}
}

// ---- Once per scene entry ---------------------------------------------------------
if (G.sceneName !== ctx.scene) {
  G.sceneName = ctx.scene
  G.start = { x: player.x, y: player.y }   // NEW: respawn point = where you designed the ninja
  G.facing = 'right'
  G.clock = 0
  G.camX = null
  G.frameOf = {}
  G.jumpHeld = false
  G.jumpBuffer = 0
  G.coyote = 0
  G.leaving = false                         // NEW: a loadScene is pending
  G.won = false                             // NEW
}
G.clock += dt

// ---- Helpers ------------------------------------------------------------------------
function setFrame(ref, name) {
  if (G.frameOf[ref.id] === name) return
  const id = G.frames[name]
  if (!id) return
  G.frameOf[ref.id] = name
  ref.image = id
}
function burst(id, x, y, count) {
  const fx = getCompByID(id)
  if (!fx) return
  fx.x = x
  fx.y = y
  fx.emit(count)
}
// NEW: set a Text node's text by Id, only when it changes.
function setText(id, value) {
  const ref = getCompByID(id)
  if (ref && ref.textContent !== value) ref.textContent = value
}

const v = player.velocity
if (!v) return

// ---- NEW: fell off the level -> back to the start -----------------------------------
if (player.y < level.fallY) {
  // Writing x / y teleports a physics body; then zero its velocity so
  // it doesn't keep its falling speed.
  player.x = G.start.x
  player.y = G.start.y
  player.velocity = { x: 0, y: 0 }
  G.camX = null
  ctx.playTone({ type: 'noise', duration: 0.25, volume: 0.2 })
  return
}

// ---- Ground check -----------------------------------------------------------------------
const onGround = [-FEET_SPREAD, FEET_SPREAD].some(
  (dx) => ctx.raycast(player.x + dx, player.y, 0, -1, FEET_RAY, player) !== null,
)
const grounded = onGround && v.y <= 1

// ---- Run (no control while leaving or after winning) -------------------------------
const frozen = G.leaving || G.won
let dir = (keys.has('right') || keys.has('d') ? 1 : 0) - (keys.has('left') || keys.has('a') ? 1 : 0)
if (frozen) dir = 0
if (dir !== 0) G.facing = dir < 0 ? 'left' : 'right'
const k = Math.min(1, dt * ACCEL)
let vx = v.x + (dir * RUN_SPEED - v.x) * k
let vy = v.y

// ---- Jump ---------------------------------------------------------------------------------
const jumpDown = !frozen && (keys.has('space') || keys.has('w') || keys.has('up'))
if (jumpDown && !G.jumpHeld) G.jumpBuffer = JUMP_BUFFER
G.jumpBuffer -= dt
G.coyote = grounded ? COYOTE_TIME : G.coyote - dt
if (G.jumpBuffer > 0 && G.coyote > 0) {
  vy = JUMP_SPEED
  G.jumpBuffer = 0
  G.coyote = 0
  ctx.playTone({ freq: 220, to: 520, type: 'square', duration: 0.12, volume: 0.12 })
}
if (!jumpDown && G.jumpHeld && vy > 0) vy *= JUMP_CUT
G.jumpHeld = jumpDown
player.velocity = { x: vx, y: vy }

// ---- Animation ------------------------------------------------------------------------
const col = G.facing === 'left' ? 2 : 3
let frame
if (!grounded) frame = 'ninja_walk ' + (1 * 4 + col)
else if (Math.abs(vx) > 10) frame = 'ninja_walk ' + ((Math.floor(G.clock * WALK_FPS) % 4) * 4 + col)
else frame = 'ninja_idle ' + ((Math.floor(G.clock * IDLE_FPS) % 4) * 4 + col)
setFrame(player, frame)

// ---- Coins ------------------------------------------------------------------------------
let coinsLeft = 0
for (const coin of getCompByClass('coin')) {
  const key = ctx.scene + ':' + coin.id
  if (G.collected[key]) {
    if (coin.visible) coin.visible = false
    continue
  }
  coinsLeft++
  setFrame(coin, 'coin ' + (Math.floor(G.clock * 8 + Math.abs(coin.x) * 0.05) % 4))
  if (Math.abs(coin.x - player.x) < PICKUP_X && Math.abs(coin.y - player.y) < PICKUP_Y) {
    G.collected[key] = true
    coin.visible = false
    coinsLeft--
    G.score += COIN_POINTS
    burst('sparkle', coin.x, coin.y, 12)
    ctx.playTone({ freq: 988, to: 1480, type: 'square', duration: 0.09, volume: 0.15 })
  }
}
ctx.props.score = G.score
ctx.props.coinsLeft = coinsLeft

// ---- NEW: the door ------------------------------------------------------------------------
const door = getCompByID('door')
if (door && !frozen && grounded && Math.abs(door.x - player.x) < DOOR_X && Math.abs(door.y - player.y) < DOOR_Y) {
  if (level.next) {
    // Next level. loadScene is deferred: this frame finishes in the
    // current scene, then the switch happens. G.leaving stops a second
    // request on the frames before it does.
    G.leaving = true
    ctx.playTone({ freq: 330, to: 660, type: 'triangle', duration: 0.3, volume: 0.2 })
    ctx.loadScene(level.next)
  } else {
    // Last door: you win.
    G.won = true
    setText('banner', 'YOU WIN!  SCORE ' + G.score)
    ctx.playTone({ freq: 523, to: 1046, type: 'triangle', duration: 0.6, volume: 0.25 })
    burst('sparkle', player.x, player.y + 8, 40)
    // When the game is embedded in a web page, the page hears this.
    ctx.emit('won', { score: G.score })
  }
}

// ---- Camera -------------------------------------------------------------------------------
const cam = getCompByID('camera')
if (cam) {
  const b = level.camera
  const tx = clamp(player.x + (G.facing === 'left' ? -LOOK_AHEAD : LOOK_AHEAD), b[0], b[2])
  const ty = clamp(player.y + 20, b[1], b[3])
  if (G.camX === null) {
    G.camX = tx
    G.camY = ty
  }
  const t = 1 - Math.exp(-8 * dt)
  G.camX += (tx - G.camX) * t
  G.camY += (ty - G.camY) * t
  cam.x = Math.round(G.camX)
  cam.y = Math.round(G.camY)
}
```

## How it works

### Deferred scene switches

`ctx.loadScene('Level 2')` doesn't switch immediately. The rest of this frame's script still runs against Level 1, and the switch happens right after. No script ever sees half of one scene and half of another. An unknown name is logged and ignored, which is why the scene names must match `LEVELS` exactly.

Level 2 then runs **its own** state machine, which runs the same file. On its first frame `G.sceneName !== ctx.scene`, so the per-scene block resets the camera, caches and respawn point.

### What survives the hop

| Thing | After `loadScene` |
|---|---|
| `ctx.globals` (`G.score`, `G.collected`) | Kept. That's what it's for. |
| The new scene's nodes | Fresh, exactly as designed. |
| The new scene's Properties | Back to their starting values. The script rewrites them from `G` every frame. |
| Data a web page set (`ctx.data`) | Kept, and re-applied to same-named Properties. |

Ninja Adventure passes a spawn point across the hop in the same way (`G.spawn = { scene, x, y }` before its `ctx.loadScene(door.to)`), because the next scene's player node doesn't exist until the switch. See [Scenes and globals](../../scripting/scenes-and-globals.mdx).

### Teleporting a physics body

Writing `player.x` / `player.y` moves the node, and the physics engine notices the script moved it and teleports the body. Setting `velocity` to zero afterwards stops it from keeping its fall speed. The `return` skips the rest of the frame, so nothing else uses the stale position.

### `ctx.emit`

`ctx.emit('won', { score })` does nothing visible in the editor (it's logged in the Console). When the game is embedded in a page, the page's `onEvent` / `player.on('event')` receives it. Lesson 7 uses that.

## Check your work

- Walking into Level 1's door plays a rising tone and Level 2 appears, with your score intact.
- Coins you took in Level 1 stay gone if you could go back (try temporarily setting Level 2's `next` to `'Level 1'`).
- Falling into a gap returns you to the level's start with a hiss of noise.
- Level 2's door shows "YOU WIN! SCORE …", sparks, and freezes the ninja. The Console shows `ctx.emit("won", …)`.
