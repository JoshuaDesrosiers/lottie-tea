# 3. Move the plate

**Goal:** while playing, the plate follows the mouse smoothly, or moves with ← and → at a steady speed. It never leaves the counter.

## Steps

Replace the empty `else` branch from lesson 2 with this:

```js title="Toast Catch, step 2 of 4: the play branch"
} else {
  // Plate: follow the mouse, or the arrow keys.
  const keys = (ctx.keysDown.has('right') ? 1 : 0) - (ctx.keysDown.has('left') ? 1 : 0)
  if (keys) g.plateX += keys * 420 * dt
  else g.plateX += (ctx.mouseX - g.plateX) * Math.min(1, dt * 14)
  g.plateX = Math.max(-270, Math.min(270, g.plateX))
  get('plate').x = g.plateX
}
```

The whole program now reads:

```js title="Toast Catch, step 2 of 4"
const POOL = 6
const g = ctx.globals.catch || (ctx.globals.catch = {
  mode: 'ready',            // 'ready' | 'play' | 'over'
  toasts: [],               // { x, y, vy, burnt, live }
  spawnIn: 0,
  plateX: 0,
  text: {},
})
const dt = ctx.deltaSeconds
const get = (id) => getCompByID(id)
const say = (id, text) => { if (g.text[id] !== text) { g.text[id] = text; get(id).textContent = text } }

function start() {
  g.mode = 'play'
  g.toasts = []
  g.spawnIn = 0.4
  ctx.props.score = 0
  ctx.props.lives = 3
  for (let i = 0; i < POOL; i++) get('toast' + i).visible = false
  say('message', '')
}

if (g.mode !== 'play') {
  if (ctx.tap || ctx.keysDown.has('space')) start()
} else {
  // Plate: follow the mouse, or the arrow keys.
  const keys = (ctx.keysDown.has('right') ? 1 : 0) - (ctx.keysDown.has('left') ? 1 : 0)
  if (keys) g.plateX += keys * 420 * dt
  else g.plateX += (ctx.mouseX - g.plateX) * Math.min(1, dt * 14)
  g.plateX = Math.max(-270, Math.min(270, g.plateX))
  get('plate').x = g.plateX
}

say('scoreText', String(ctx.props.score))
for (let i = 0; i < 3; i++) get('life' + i).visible = i < ctx.props.lives
```

Try it in **Playground**: click to start, then move the mouse across the game, and hold the arrow keys.

## How it works

- **One number for direction.** `keys` is `1` while → is held, `-1` while ← is held, and `0` for neither or both. Multiplying by it turns "which key" into "which way".
- **Keys move at a constant speed.** `420 * dt` is 420 units per second, whatever the frame rate. Crossing the 540-unit counter takes about 1.3 seconds.
- **The mouse eases the plate.** Each frame the plate covers a fraction of the remaining distance to `ctx.mouseX`: `dt * 14`, about 23% per frame at 60 fps. Far away it moves fast, close by it slows down, so it feels weighty without lagging. `Math.min(1, …)` stops a long frame (a tab switch, a hitch) from overshooting.
- **Keys win over the mouse.** When an arrow is held, the mouse is ignored. When it is released, the plate eases from wherever it is toward the mouse.
- **`ctx.mouseX` is in world units**, the same coordinates as node positions, with 0 in the middle of the scene. No conversion from screen pixels is needed.
- **The clamp keeps the plate on screen.** The plate is 96 wide, so at x ±270 its edge is 2 units from the frame's edge at ±320.
- **The state lives in `g.plateX`, not in the node.** The program writes the node's `x` every frame from its own number. Keeping the source of truth in `ctx.globals` makes the rest of the game (catching, in lesson 5) read one value.

## Check your work

- The plate tracks the mouse and settles on it without shaking.
- Holding → moves it to the right edge and stops it there.
- Before you click to start, the plate does not move.
