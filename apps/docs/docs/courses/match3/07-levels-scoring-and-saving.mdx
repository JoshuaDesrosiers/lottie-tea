# 7. Levels, scoring and saving

**Goal:** understand everything around the board: winning and losing, stars, saved progress, the result screen, hints and the heads-up display. Then make the game yours.

**What you'll learn**

- A "bonus countdown" with a timer.
- Stars from score thresholds, and saving the best result.
- Writing progress with `ctx.storage.set`.
- A staged result panel (scale-in, stars one by one).
- An idle hint, a moves warning, a score bar and screen shake.

## Winning, losing and the result panel

```js title="demo_match3.js — //@program Game (end of level)"
// Win: leftover moves pay out, then the result panel.
if (g.phase === 'won') {
  if (g.moves > 0 && g.timer > 0.25) {
    g.timer = 0
    g.moves--
    g.score += 250
    const p = g.pieces[Math.floor(Math.random() * g.pieces.length)]
    if (p) { blast(p); floatText('+250', p.x, p.y + BOARD_Y) }
  } else if (g.moves <= 0 && g.timer > 0.8 && !g.result) finish(true)
}
if (g.phase === 'lost' && g.timer > 1.0 && !g.result) finish(false)

function finish(won) {
  const def = g.def
  const stars = won ? Math.max(1, def.stars.filter((s) => g.score >= s).length) : 0
  g.result = { won, stars, shown: 0, t: 0 }
  if (won) {
    save.stars[def.n] = Math.max(save.stars[def.n] || 0, stars)
    save.best[def.n] = Math.max(save.best[def.n] || 0, g.score)
    save.unlocked = Math.max(save.unlocked, def.n + 1)
    save.coins += 20 + stars * 10
    persist()
    const conf = ref('confetti')
    conf.x = 0; conf.y = 120
    conf.emit(120)
  }
  for (const id of ['dim', 'panel', 'resultTitle', 'resultSub', 'resultStar0', 'resultStar1', 'resultStar2', 'nextBtn', 'nextLabel', 'map2Btn', 'map2Label']) show(id, true)
  setText('resultTitle', won ? 'VICTORY!' : 'SO CLOSE!')
  setText('resultSub', won ? 'SCORE ' + g.score + '   +' + (20 + stars * 10) + ' COINS' : 'OUT OF MOVES')
  setText('nextLabel', won ? (def.n < LEVEL_COUNT ? 'NEXT LEVEL' : 'FINISH') : 'TRY AGAIN')
  for (let k = 0; k < 3; k++) ref('resultStar' + k).fillColor = [0.3, 0.28, 0.4, 1]
}

// Result panel: stars pop in one by one; buttons.
if (g.result) {
  const res = g.result
  res.t += dt
  const panelScale = Math.min(1, res.t / 0.25)
  ref('panel').scaleX = 0.6 + panelScale * 0.4; ref('panel').scaleY = 0.6 + panelScale * 0.4
  while (res.shown < res.stars && res.t > 0.4 + res.shown * 0.35) {
    const star = ref('resultStar' + res.shown)
    star.fillColor = [1, 0.85, 0.2, 1]
    const pop = g.pops[3]
    pop.x = star.x; pop.y = star.y
    pop.emit(16)
    res.shown++
  }
  for (let k = 0; k < 3; k++) {
    const s = k < res.shown ? 1 + Math.max(0, 0.4 - (res.t - 0.4 - k * 0.35)) : 0.85
    ref('resultStar' + k).scaleX = s; ref('resultStar' + k).scaleY = s
  }
  if (res.t > 0.5) {
    if (button('next', 0, -62, 170, 42)) {
      if (res.won && g.def.n < LEVEL_COUNT) S.level = g.def.n + 1
      if (res.won && g.def.n >= LEVEL_COUNT) go('Crown Match Levels')
      else { g.result = null; startLevel() }
    } else if (button('map2', 0, -114, 170, 42)) go('Crown Match Levels')
  }
}
```

### How it works

**Leftover moves pay out.** In `won`, every 0.25 s one move is spent for 250 points, with a blast on a random gem and a floating "+250". When no moves are left and 0.8 s have passed, `finish(true)`. A loss waits 1 s, then `finish(false)`.

Notice `finish` is a function declaration placed *after* the code that calls it. JavaScript hoists function declarations to the top of the script, so that's fine.

**Stars.** `def.stars` holds three score thresholds; `def.stars.filter((s) => g.score >= s).length` counts how many you passed. Completing the goals always earns at least one (`Math.max(1, …)`).

**Saving.** On a win:

```js
save.stars[def.n] = Math.max(save.stars[def.n] || 0, stars)    // keep the best
save.best[def.n] = Math.max(save.best[def.n] || 0, g.score)
save.unlocked = Math.max(save.unlocked, def.n + 1)            // never re-lock
save.coins += 20 + stars * 10
persist()                                                      // ctx.storage.set('crownmatch', save)
```

Replaying a level can only improve your record. `persist()` is called once per finished level, not every frame: storage writes are slow compared with ordinary script work. Because `save` is the same object as `S.save`, the Home and Levels screens show the new stars immediately, and after a reload `ctx.storage.get` brings them back.

**Confetti.** The `confetti` Particle System is moved to the top of the screen and fires 120 particles.

**The panel.** `finish` shows the overlay's nodes and sets its texts. Then the `if (g.result)` block animates it every frame from `res.t`:

- the panel scales from 0.6 to 1 over 0.25 s;
- star `k` lights up at `0.4 + k * 0.35` s with a burst of topaz sparkles, and its scale starts at 1.4 and settles to 1 (`1 + max(0, 0.4 - age)`); unearned stars stay small and grey;
- after 0.5 s the NEXT (or TRY AGAIN) and MAP buttons respond.

NEXT on a win advances `S.level` and calls `startLevel()` in place, without reloading the scene: `g.result = null` hides the panel's logic, and `startLevel` hides its nodes and refills the board from the free pool.

## Hints and the HUD

```js title="demo_match3.js — //@program Game (selection, hints, HUD)"
// Selection ring.
const selRef = ref('sel')
selRef.visible = !!g.selected && g.phase === 'idle'
if (g.selected) { selRef.x = lx(g.selected[1]); selRef.y = ly(g.selected[0]) }

// Hint after a few idle seconds.
if (g.phase === 'idle') {
  g.idleT += dt
  if (g.idleT > 5 && !g.hint) { const m = hasMove(); g.hint = Array.isArray(m) ? m : null }
} else { g.idleT = 0; g.hint = null }

// HUD.
setText('movesText', String(Math.max(0, g.moves)))
ref('movesBadge').fillColor = g.moves <= 3 && g.phase !== 'won' ? [1, 0.55 + Math.sin(T * 8) * 0.25, 0.55, 1] : [1, 1, 1, 1]
for (let k = 0; k < g.goals.length; k++) {
  const goal = g.goals[k]
  setText('goalText' + k, goal.left > 0 ? String(goal.left) : 'DONE')
  ref('goalText' + k).fillColor = goal.left > 0 ? [1, 1, 1, 1] : [0.5, 1, 0.55, 1]
}
setText('scoreText', String(g.score))
const frac = Math.min(1, g.score / g.def.stars[2])
const fill = ref('scoreFill')
fill.scaleX = Math.max(0.01, frac)
fill.x = Math.round(-148 + 148 * frac)
for (let k = 0; k < 3; k++) ref('barStar' + k).fillColor = g.score >= g.def.stars[k] ? [1, 0.85, 0.2, 1] : [0.35, 0.32, 0.45, 1]
for (const f of g.floats) {
  if (f.t <= 0) continue
  f.t -= dt
  f.y += 40 * dt
  f.ref.x = Math.round(f.x); f.ref.y = Math.round(f.y)
  if (f.t <= 0) { f.ref.textContent = ''; f.ref.y = 10000 }
}
if (g.bannerT > 0) { g.bannerT -= dt; if (g.bannerT <= 0) banner('', '', 0) }
const shake = g.shake > 0 ? (g.shake -= dt, g.shake) : 0
const board = ref('board')
board.x = shake > 0 ? Math.round((Math.random() - 0.5) * 8 * shake / 0.3) : 0
setText('tip', g.phase === 'won' ? 'WELL DONE!' : g.combo >= 2 ? 'COMBO x' + g.combo : 'DRAG A GEM TO SWAP')
if (!g.result && (button('quit', -128, -264, 84, 34) || keys.has('escape'))) go('Crown Match Levels')

```

### How it works

- **Selection ring**: visible only for a selected gem in `idle`, moved to that cell.
- **Hint**: `g.idleT` counts idle seconds; after 5 s, `hasMove()`'s first working pair is stored in `g.hint` and the visuals pass wiggles those two gems. Any other phase clears it.
- **Moves warning**: with 3 or fewer moves left, the moves badge flashes red (`sin(T * 8)` on its green and blue channels).
- **Goals**: each goal slot shows how many are left, or a green "DONE".
- **Score bar**: `scoreFill` is scaled horizontally by the fraction of the three-star score reached, and shifted so it grows from the left edge (a shape scales around its centre, so `x` moves by half the width). Star markers turn gold as you pass them.
- **Floating texts** rise at 40 units/s for 0.9 s, then park off-screen.
- **Shake**: while `g.shake` counts down, the whole board (and every gem in it, as its children) jitters by up to 4 units.
- **Leaving**: MAP or Escape go back to the level map.

## Make it yours

Now that you know every part, here are projects that touch each system. Try them in the `Game` script.

1. **A timed mode.** Add `g.timeLeft = 60` in `startLevel`, subtract `dt` each frame while `g.phase === 'idle'`, show it in `movesText`, and treat `g.timeLeft <= 0` like running out of moves in the `settle` phase.
2. **A new special.** Make a 6-in-a-row (only possible with cascades) clear two random colours. In `resolve`, check `run.cells.length >= 6` before the `>= 5` case; in `clearCells`, handle your new `sp` value by pushing the cells of two colours.
3. **A new goal type.** Count rockets fired: add a goal `{ t: 'rocket', n: 5 }` in `levelDef`, call `bumpGoal('rocket')` in `clearCells` when `p.sp` is `'h'` or `'v'`, and give it an icon in `startLevel`.
4. **Report results to a web page.** When embedding the game (see the [like button course](../react-like-button/04-export-and-embed.mdx)), add `ctx.emit('levelDone', { level: def.n, won, stars, score: g.score })` at the end of `finish`, and listen for it with `onEvent`.
5. **Reset progress.** Add a hidden reset to the Home program: `if (keys.has('r') && keys.has('shift')) { ctx.storage.remove('crownmatch'); S.save = null }`. (`ctx.storage.remove(key)` deletes a saved key; the next frame reloads the defaults.)

## Check your work

- Win level 1 with moves to spare and watch the bonus countdown, the stars appearing one by one, and confetti.
- Go back to the map: level 1 shows your stars, level 2 is green and pulsing.
- Reload the page (or restart Playground) and open the map again: your progress is still there.
- Leave the board alone for 5 seconds: two gems wiggle.
