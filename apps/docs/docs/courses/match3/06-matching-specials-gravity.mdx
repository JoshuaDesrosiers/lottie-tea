# 6. Matching, specials and gravity

**Goal:** understand the heart of any match-3: find matches, clear them (with chain reactions), drop what's left, refill, and repeat until the board settles.

**What you'll learn**

- Scanning rows and columns for runs of 3+.
- Detecting whether *any* move exists, and shuffling when none does.
- A breadth-first "blast queue" so specials set each other off.
- Creating specials from run shapes (4, L/T, 5).
- Combining two specials.
- Column-by-column gravity with refill.
- The `clear` → `fall` → `settle` phases, cascades and combo counting.
- Gravity-style falling and squash in the visuals pass.

## Finding matches and moves

```js title="demo_match3.js — //@program Game (matching)"
// --------------------------------------------------------- matching --

/** Every run of 3+ same-colored gems: [{ cells: [[r, c]...], dir }]. */
function findRuns() {
  const runs = []
  const key = (p) => (p && p.sp !== 'light' ? p.t : -1)
  for (let r = 0; r < N; r++) {
    let c = 0
    while (c < N) {
      const t = key(at(r, c))
      let e = c + 1
      while (e < N && t >= 0 && key(at(r, e)) === t) e++
      if (t >= 0 && e - c >= 3) runs.push({ dir: 'h', cells: Array.from({ length: e - c }, (_, k) => [r, c + k]) })
      c = e
    }
  }
  for (let c = 0; c < N; c++) {
    let r = 0
    while (r < N) {
      const t = key(at(r, c))
      let e = r + 1
      while (e < N && t >= 0 && key(at(e, c)) === t) e++
      if (t >= 0 && e - r >= 3) runs.push({ dir: 'v', cells: Array.from({ length: e - r }, (_, k) => [r + k, c]) })
      r = e
    }
  }
  return runs
}

function hasMove() {
  for (let r = 0; r < N; r++) for (let c = 0; c < N; c++) {
    const p = at(r, c)
    if (!p) continue
    if (p.sp === 'light') return true
    for (const [dr, dc] of [[0, 1], [1, 0]]) {
      const q = at(r + dr, c + dc)
      if (!q) continue
      if (p.sp && q.sp) return true
      // Try the swap.
      g.grid[r][c] = q; g.grid[r + dr][c + dc] = p
      const ok = makesRun(r, c, q.t) || makesRun(r + dr, c + dc, p.t)
      g.grid[r][c] = p; g.grid[r + dr][c + dc] = q
      if (ok) return [[r, c], [r + dr, c + dc]]
    }
  }
  return false
}

function shuffle() {
  const pieces = g.pieces.filter((p) => !p.sp)
  for (let tries = 0; tries < 60; tries++) {
    const types = pieces.map((p) => p.t).sort(() => Math.random() - 0.5)
    pieces.forEach((p, i) => { p.t = types[i] })
    if (!findRuns().length && hasMove()) break
  }
  for (const p of pieces) lookOf(p)
}
```

### `findRuns`

For each row, walk left to right: from column `c`, extend `e` while the next gem has the same type, then if the run is 3 or longer record it with its direction and cells, and continue from `e`. Then the same down each column. `key(p)` returns `-1` for empty cells and Light Balls, so they never take part in an ordinary run. A gem in both a horizontal and a vertical run appears in two runs: that's how L and T shapes are spotted later.

### `hasMove`

Try every swap with the right and lower neighbour: do it in the grid, ask `makesRun` (lesson 4) about both cells, undo it. Any Light Ball, or two adjacent specials, always count as a move. It returns the first working pair, which the hint system reuses (lesson 7).

### `shuffle`

Shuffle the types of all ordinary gems (specials stay put) until the board has no ready-made runs and at least one move, up to 60 tries, then update each gem's look.

## Clearing, with chain reactions

```js title="demo_match3.js — //@program Game (clearing)"
// -------------------------------------------------------- clearing --

/**
 * Clears `cells` (a Set of "r,c"), detonating any specials caught in it
 * (which add their own cells), skipping cells in `keep` (where a new
 * special is being born). Counts goals, frost and score; starts the pop.
 */
function clearCells(cells, keep) {
  const queue = [...cells]
  const done = new Set()
  let cleared = 0, cx = 0, cy = 0
  while (queue.length) {
    const k = queue.shift()
    if (done.has(k)) continue
    done.add(k)
    const [r, c] = k.split(',').map(Number)
    if (!playable(r, c)) continue
    const p = g.grid[r][c]
    // Frost under the cell breaks (one layer per hit).
    const i = r * N + c
    if (g.frost[i] > 0) {
      g.frost[i]--
      refreshFrost(i)
      if (g.frost[i] === 0) bumpGoal('frost')
    }
    if (!p || p.pop > 0 || (keep && keep.has(k))) continue
    // A special in the blast goes off too.
    if (p.sp === 'h') for (let cc = 0; cc < N; cc++) queue.push(r + ',' + cc)
    if (p.sp === 'v') for (let rr = 0; rr < N; rr++) queue.push(rr + ',' + c)
    if (p.sp === 'bomb') for (let dr = -2; dr <= 2; dr++) for (let dc = -2; dc <= 2; dc++) queue.push((r + dr) + ',' + (c + dc))
    if (p.sp === 'light') {
      const colors = g.pieces.filter((q) => !q.sp && q.pop === 0).map((q) => q.t)
      const t = colors.length ? colors[Math.floor(Math.random() * colors.length)] : 0
      for (const q of g.pieces) if (q.t === t && !q.sp) queue.push(q.r + ',' + q.c)
    }
    if (p.sp) { g.score += 200; blast(p) }
    p.pop = 0.2
    if (p.sp !== 'light') bumpGoal(p.t)
    cleared++
    cx += p.x; cy += p.y
    const pop = g.pops[p.sp === 'light' ? 6 : p.t]
    pop.x = Math.round(p.x); pop.y = Math.round(p.y + BOARD_Y)
    pop.emit(7)
  }
  if (cleared) {
    const points = Math.round(cleared * 60 * (1 + g.combo * 0.5))
    g.score += points
    floatText('+' + points, cx / cleared, cy / cleared + BOARD_Y)
  }
  return cleared
}

function bumpGoal(t) {
  for (const goal of g.goals) if (goal.t === t && goal.left > 0) { goal.left--; break }
}

function blast(p) {
  const b = ref('blast')
  b.x = Math.round(p.x); b.y = Math.round(p.y + BOARD_Y)
  b.emit(30)
}

function floatText(text, x, y) {
  const f = g.floats[g.floatNext++ % g.floats.length]
  f.t = 0.9; f.x = x; f.y = y
  f.ref.textContent = text
}
```

### `clearCells`: a breadth-first blast queue

`cells` is a set of `"r,c"` strings. The function treats it as a **queue**: take a cell, skip it if already done, otherwise:

1. Break one layer of frost under it (counting the frost goal when it's gone).
2. Skip empty cells, gems already popping, and cells in `keep` (where a new special is being born).
3. If the gem is a special, **push its blast onto the queue**: a whole row (`'h'`), column (`'v'`), 5 × 5 square (`'bomb'`), or every gem of one random colour (`'light'`).
4. Start the gem's pop (`p.pop = 0.2` seconds), count it toward its colour goal, and fire 7 sparkles from that colour's particle system.

Because blasts go back on the queue, a rocket that hits TNT sets the TNT off, which can hit another rocket, and so on, with each cell handled once. Points are `60 per gem × (1 + 0.5 × combo)`, shown as a floating "+N" at the average position of everything cleared.

`floatText` reuses six text nodes round-robin (`g.floatNext++ % 6`), the same pooling idea as the gems.

## Making specials

```js title="demo_match3.js — //@program Game (resolve and combo)"
/** Resolves the board after a swap or a fall: matches -> specials + clears. */
function resolve(swapped) {
  const runs = findRuns()
  if (!runs.length) return false
  const clear = new Set(), keep = new Set()
  const inRun = new Map()
  for (const run of runs) for (const [r, c] of run.cells) {
    clear.add(r + ',' + c)
    inRun.set(r + ',' + c, (inRun.get(r + ',' + c) || []).concat([run]))
  }
  // Specials are born where the player swapped (if part of the run), else
  // in the run's middle.
  const birthCell = (run) => {
    for (const s of swapped || []) if (run.cells.some(([r, c]) => r === s[0] && c === s[1])) return s
    return run.cells[Math.floor(run.cells.length / 2)]
  }
  const born = []
  // L / T: a cell in both a horizontal and a vertical run -> TNT.
  for (const [k, list] of inRun) {
    if (list.some((x) => x.dir === 'h') && list.some((x) => x.dir === 'v')) { const [r, c] = k.split(',').map(Number); born.push({ r, c, sp: 'bomb' }); list.forEach((x) => { x.used = true }) }
  }
  for (const run of runs) {
    if (run.used) continue
    if (run.cells.length >= 5) { const [r, c] = birthCell(run); born.push({ r, c, sp: 'light' }) }
    else if (run.cells.length === 4) { const [r, c] = birthCell(run); born.push({ r, c, sp: run.dir === 'h' ? 'v' : 'h' }) }
  }
  for (const b of born) {
    const k = b.r + ',' + b.c
    if (keep.has(k)) continue
    const p = g.grid[b.r][b.c]
    if (!p || p.sp) continue
    keep.add(k)
    bumpGoal(p.t)
    p.sp = b.sp
    lookOf(p)
    p.scale = 1.5
  }
  clearCells(clear, keep)
  return true
}

/** Swapping two specials (or a Light Ball with anything) combines them. */
function combo(a, b) {
  const cells = new Set()
  const addRow = (r) => { for (let c = 0; c < N; c++) cells.add(r + ',' + c) }
  const addCol = (c) => { for (let r = 0; r < N; r++) cells.add(r + ',' + c) }
  if (a.sp === 'light' || b.sp === 'light') {
    const ball = a.sp === 'light' ? a : b, other = ball === a ? b : a
    cells.add(ball.r + ',' + ball.c)
    if (other.sp === 'light') { for (const p of g.pieces) cells.add(p.r + ',' + p.c) }
    else {
      for (const p of g.pieces) if (p.t === other.t && !p.sp) {
        // Ball + special: every gem of that color becomes that special.
        if (other.sp) { p.sp = other.sp; lookOf(p) }
        cells.add(p.r + ',' + p.c)
      }
      cells.add(other.r + ',' + other.c)
    }
    ball.sp = null  // spent (don't fire a random color as well)
    g.score += 500
  } else {
    const kinds = [a.sp, b.sp].sort().join('+')
    if (kinds === 'bomb+bomb') { for (let dr = -3; dr <= 3; dr++) for (let dc = -3; dc <= 3; dc++) cells.add((b.r + dr) + ',' + (b.c + dc)) }
    else if (kinds.includes('bomb')) { for (let d = -1; d <= 1; d++) { addRow(b.r + d); addCol(b.c + d) } }
    else { addRow(b.r); addCol(b.c) }
    a.sp = b.sp = null
    cells.add(a.r + ',' + a.c); cells.add(b.r + ',' + b.c)
    g.score += 400
  }
  blast(b)
  g.shake = 0.3
  clearCells(cells, null)
}
```

### `resolve`

1. Collect every cell of every run into `clear`, and remember which runs each cell belongs to.
2. **L / T → TNT**: any cell in both a horizontal and a vertical run becomes a `'bomb'`, and both runs are marked used.
3. **5+ → Light Ball**, **4 → Rocket** for the remaining runs. A horizontal 4 makes a *vertical* rocket and vice versa (`run.dir === 'h' ? 'v' : 'h'`), as in the games this demo is modelled on.
4. The special is born at the cell the player swapped into, if that cell is in the run (`birthCell`), else in the run's middle. The newborn special's cell goes into `keep`, so `clearCells` spares it; it counts toward its colour goal, takes its new look, and pops in at 1.5× scale.
5. `clearCells(clear, keep)` clears the rest.

### `combo`

Swapping two specials (or a Light Ball with anything) skips matching entirely:

| Swap | Effect |
|---|---|
| Light Ball + gem | Every gem of that colour clears. |
| Light Ball + special | Every gem of that colour **becomes** that special, then they all go off. |
| Light Ball + Light Ball | The whole board. |
| TNT + TNT | A 7 × 7 square. |
| TNT + Rocket | Three rows and three columns. |
| Rocket + Rocket | A cross: one row and one column. |

Then a big `blast` burst and a short board shake (`g.shake = 0.3`).

## Gravity and refill

```js title="demo_match3.js — //@program Game (gravity)"
/** Removes popped pieces, drops the rest, refills from the top. */
function gravity() {
  for (const p of g.pieces) if (p.pop > 0) { g.grid[p.r][p.c] = null; freePiece(p) }
  g.pieces = g.pieces.filter((p) => p.pop === 0)
  for (let c = 0; c < N; c++) {
    let write = N - 1
    for (let r = N - 1; r >= 0; r--) {
      if (!playable(r, c)) continue
      while (write >= 0 && !playable(write, c)) write--
      const p = g.grid[r][c]
      if (!p) continue
      if (write !== r) { g.grid[write][c] = p; g.grid[r][c] = null; p.r = write }
      write--
      while (write >= 0 && !playable(write, c)) write--
    }
    let spawned = 0
    for (let r = N - 1; r >= 0; r--) {
      if (!playable(r, c) || g.grid[r][c]) continue
      spawned++
      const p = newPiece(Math.floor(Math.random() * g.def.colors), r, c, ly(0) + spawned * CELL + 10)
      g.grid[r][c] = p
      g.pieces.push(p)
    }
  }
}

const goalsDone = () => g.goals.every((x) => x.left <= 0)
const settled = () => g.pieces.every((p) => Math.abs(p.y - ly(p.r)) < 0.5 && Math.abs(p.x - lx(p.c)) < 0.5)
```

### `gravity`

1. Free every popped piece (its node goes back to the pool) and drop it from the grid.
2. For each column, walk from the bottom up with a `write` pointer to the lowest free playable cell. Each piece found moves down to `write` (only its grid cell and `r` change; it's still *drawn* where it was). Holes are skipped on both pointers, so gems fall "through" a hole to the cell below it.
3. Fill the empty cells at the top with new random pieces, stacked above the board (`ly(0) + spawned * CELL + 10`) so they fall in in order.

`settled()` is true when every piece is drawn at its cell, which is how the phases know the fall is over.

## The phases that run all this

```js title="demo_match3.js — //@program Game (clear, fall, settle)"
} else if (g.phase === 'clear') {
  if (g.timer >= 0.2) { gravity(); g.phase = 'fall'; g.timer = 0 }
} else if (g.phase === 'fall') {
  if (settled()) {
    g.combo++
    if (resolve(null)) {
      g.phase = 'clear'
      g.timer = 0
      if (g.combo >= 2) banner(['', '', 'GOOD!', 'GREAT!', 'AMAZING!', 'ROYAL!'][Math.min(5, g.combo)] || 'ROYAL!', '', 0.8)
    } else g.phase = 'settle'
  }
} else if (g.phase === 'settle') {
  g.phase = 'idle'
  g.idleT = 0
  if (goalsDone()) { g.phase = 'won'; g.timer = 0; banner('LEVEL COMPLETE!', g.moves > 0 ? 'BONUS: ' + g.moves + ' MOVES LEFT' : '', 1.6) }
  else if (g.moves <= 0) { g.phase = 'lost'; g.timer = 0; banner('OUT OF MOVES', '', 1.2) }
  else if (!hasMove()) { shuffle(); banner('SHUFFLE!', 'NO MOVES LEFT', 1.0) }
}
```

After a successful swap the board is in `clear`:

1. **`clear`**: wait 0.2 s for the pops to play, then `gravity()` → `fall`.
2. **`fall`**: wait until `settled()`. Then `g.combo++` and try `resolve(null)` again: new matches made by falling gems are a **cascade**, back to `clear` with a bigger multiplier and a banner from GOOD! (2) up to ROYAL! (5+). No matches → `settle`.
3. **`settle`**: back to `idle`, unless the goals are done (`won`), you're out of moves (`lost`), or no move exists (shuffle with a banner).

## The visuals pass: falling and squash

At the end of every frame, the data is drawn:

```js title="demo_match3.js — //@program Game (visuals)"
// ---------------------------------------------------------- visuals --

for (const p of g.pieces) {
  const tx = lx(p.c), ty = ly(p.r)
  if (g.phase !== 'swap' && g.phase !== 'unswap') {
    // Fall with gravity and a little bounce; slide sideways if needed.
    if (p.y > ty + 0.01) {
      p.vy += 1600 * dt
      p.y = Math.max(ty, p.y - p.vy * dt)
      if (p.y === ty) { p.vy = 0; p.scale = 0.9 }
    } else { p.y = ty; p.vy = 0 }
    p.x += (tx - p.x) * Math.min(1, dt * 18)
  }
  if (p.pop > 0) { p.pop = Math.max(0.0001, p.pop - dt); p.scale = Math.max(0.05, p.pop / 0.2) * 1.2 }
  else p.scale += (1 - p.scale) * Math.min(1, dt * 10)
  const vis = g.vis[p.v]
  const rx = Math.round(p.x * 2) / 2, ry = Math.round(p.y * 2) / 2
  if (vis.lastX !== rx || vis.lastY !== ry) { vis.ref.x = rx; vis.ref.y = ry; vis.lastX = rx; vis.lastY = ry }
  // Hint wiggle / selection pulse.
  let s = p.scale
  const sel = g.selected && g.selected[0] === p.r && g.selected[1] === p.c
  if (sel) s *= 1.08 + Math.sin(T * 10) * 0.04
  if (g.hint && g.hint.some(([r, c]) => r === p.r && c === p.c)) s *= 1 + Math.abs(Math.sin(T * 7)) * 0.12
  const rs = Math.round(s * 50) / 50
  if (vis.lastS !== rs) { vis.ref.scaleX = rs; vis.ref.scaleY = rs; vis.lastS = rs }
  if (p.sp === 'light') {
    vis.ref.rotation = (T * 120) % 360
    const h = T * 2
    vis.ref.fillColor = [0.6 + 0.4 * Math.sin(h), 0.6 + 0.4 * Math.sin(h + 2.1), 0.6 + 0.4 * Math.sin(h + 4.2), 1]
  }
}
```

- **Falling**: a piece above its cell accelerates downward (`p.vy += 1600 * dt`) and lands exactly on it (`Math.max(ty, …)`), then squashes to 0.9 scale. Sideways it eases toward its column (`dt * 18`).
- **Popping**: `p.pop` counts down and the scale shrinks with it, after a 1.2× bump.
- **Recovering**: any other scale eases back to 1, which turns the 1.5× special birth and the 0.9× landing into springy pops.
- **Rounding before writing**: positions are rounded to half pixels and scales to 1/50, and only written when they differ from `vis.lastX` / `lastY` / `lastS`. With 64 gems, that saves hundreds of engine calls a frame when the board is still.
- **Extras**: the selected gem pulses, hinted gems wiggle, and a Light Ball spins and cycles colour with three phase-shifted sines.

## Check your work

- Make TNT bigger: in `clearCells`, change both `-2` / `2` in the bomb loop to `-3` / `3`.
- Slow gravity: change `1600` to `400` and watch gems float down.
- Score more for combos: change `(1 + g.combo * 0.5)` to `(1 + g.combo)` and chain a cascade.
- Disable specials: in `resolve`, comment out the three `born.push(...)` calls (one in the L / T loop, two in `for (const run of runs)`). Every match is now a plain clear.
