# 5. Input and swapping

**Goal:** understand how a drag or two taps become a swap, and how the swap animates and bounces back when it makes no match.

**What you'll learn**

- Turning a world-space pointer into a grid cell.
- Press / release edges from the held `'mouse'` key.
- Supporting both drag-to-swap and tap-then-tap.
- The phase machine: `g.phase` and `g.timer`.
- A linear tween between two cells, and a "swap back".

## The input code

```js title="demo_match3.js — //@program Game (input)"
// ------------------------------------------------------------ input --

function cellAt(mx, my) {
  const c = Math.round((mx + 140) / CELL), r = Math.round((140 - (my - BOARD_Y)) / CELL)
  return playable(r, c) && Math.abs(mx - lx(c)) < CELL / 2 && Math.abs(my - BOARD_Y - ly(r)) < CELL / 2 ? [r, c] : null
}

function trySwap(a, b) {
  const p = at(a[0], a[1]), q = at(b[0], b[1])
  if (!p || !q || Math.abs(a[0] - b[0]) + Math.abs(a[1] - b[1]) !== 1) return
  g.selected = null
  g.grid[a[0]][a[1]] = q; g.grid[b[0]][b[1]] = p
  ;[p.r, p.c, q.r, q.c] = [q.r, q.c, p.r, p.c]
  g.swap = { p, q, a, b, from: [[lx(a[1]), ly(a[0])], [lx(b[1]), ly(b[0])]] }
  g.phase = 'swap'
  g.timer = 0
}

function input() {
  const down = keys.has('mouse')
  const pressed = down && !g.mouseWas
  const released = !down && g.mouseWas
  g.mouseWas = down
  if (g.phase !== 'idle') { g.press = null; return }
  if (pressed) {
    const cell = cellAt(ctx.mouseX, ctx.mouseY)
    g.press = cell ? { cell, x: ctx.mouseX, y: ctx.mouseY, moved: false } : null
  }
  if (g.press && down && !g.press.moved) {
    const dx = ctx.mouseX - g.press.x, dy = ctx.mouseY - g.press.y
    if (Math.hypot(dx, dy) > 14) {
      g.press.moved = true
      const [r, c] = g.press.cell
      const target = Math.abs(dx) > Math.abs(dy) ? [r, c + Math.sign(dx)] : [r - Math.sign(dy), c]
      trySwap([r, c], target)
    }
  }
  if (released && g.press && !g.press.moved) {
    const cell = g.press.cell
    if (g.selected && Math.abs(g.selected[0] - cell[0]) + Math.abs(g.selected[1] - cell[1]) === 1) trySwap(g.selected, cell)
    else g.selected = g.selected && g.selected[0] === cell[0] && g.selected[1] === cell[1] ? null : cell
  }
  if (released) g.press = null
}
```

## The swap phases

The main loop starts by reading input and advancing the phase timer:

```js title="demo_match3.js — //@program Game (game loop: swap and unswap)"
// --------------------------------------------------- the game loop --

input()
g.timer += dt
if (g.phase === 'intro' && settled() && g.timer > 1.2) { g.phase = 'idle'; g.idleT = 0 }

if (g.phase === 'swap') {
  const k = Math.min(1, g.timer / 0.16)
  const { p, q, from } = g.swap
  p.x = from[0][0] + (from[1][0] - from[0][0]) * k; p.y = from[0][1] + (from[1][1] - from[0][1]) * k
  q.x = from[1][0] + (from[0][0] - from[1][0]) * k; q.y = from[1][1] + (from[0][1] - from[1][1]) * k
  if (k >= 1) {
    g.combo = 0
    const special = p.sp === 'light' || q.sp === 'light' || (p.sp && q.sp)
    if (special) { g.moves--; combo(p, q); g.phase = 'clear'; g.timer = 0 }
    else if (resolve([[p.r, p.c], [q.r, q.c]])) { g.moves--; g.phase = 'clear'; g.timer = 0 }
    else {
      // No match: swap back.
      const { a, b } = g.swap
      g.grid[a[0]][a[1]] = p; g.grid[b[0]][b[1]] = q
      ;[p.r, p.c, q.r, q.c] = [a[0], a[1], b[0], b[1]]
      g.swap.from = [[lx(b[1]), ly(b[0])], [lx(a[1]), ly(a[0])]]
      g.phase = 'unswap'
      g.timer = 0
    }
  }
} else if (g.phase === 'unswap') {
  const k = Math.min(1, g.timer / 0.16)
  const { p, q, from } = g.swap
  p.x = from[0][0] + (from[1][0] - from[0][0]) * k; p.y = from[0][1] + (from[1][1] - from[0][1]) * k
  q.x = from[1][0] + (from[0][0] - from[1][0]) * k; q.y = from[1][1] + (from[0][1] - from[1][1]) * k
  if (k >= 1) g.phase = 'idle'
```

## How it works

### Pointer to cell: `cellAt`

```js
const c = Math.round((mx + 140) / CELL), r = Math.round((140 - (my - BOARD_Y)) / CELL)
```

This inverts `lx` / `ly` from lesson 4: subtract the board offset, divide by the cell size, round to the nearest cell. The second line then checks the cell is playable and that the pointer is within half a cell of its centre; otherwise `null`.

### Press and release edges

`ctx.keysDown.has('mouse')` is `true` while a mouse button or finger is down. Comparing with last frame's value (`g.mouseWas`) gives the two moments that matter:

```js
const pressed = down && !g.mouseWas
const released = !down && g.mouseWas
```

Input is ignored outside the `idle` phase (`g.press = null; return`), so you can't swap while gems are falling.

### Drag to swap

On press over a gem, `g.press` records the cell and pointer position. While held, once the pointer has moved more than 14 units, the drag's dominant axis picks the neighbour:

```js
const target = Math.abs(dx) > Math.abs(dy) ? [r, c + Math.sign(dx)] : [r - Math.sign(dy), c]
```

(`r - Math.sign(dy)`: dragging *up* is positive `dy` but means a *smaller* row number.) `g.press.moved = true` ensures one drag makes one swap.

### Tap, then tap

If the pointer is released without having dragged, it was a tap. If a gem is already selected and this one is its neighbour, swap them. Otherwise select this gem (or deselect it if it was already selected). The `sel` ring follows `g.selected` in the visuals pass.

### `trySwap`: swap the data first

`trySwap` rejects anything that isn't two existing, orthogonally adjacent pieces (`Math.abs(dr) + Math.abs(dc) !== 1`). Then it swaps them **in the grid immediately**, updates their `r` / `c`, records where each one started drawing (`from`), and enters the `swap` phase. Matching code that runs at the end of the swap can then simply look at the grid.

### The `swap` phase: a 0.16 s tween

```js
const k = Math.min(1, g.timer / 0.16)
p.x = from[0][0] + (from[1][0] - from[0][0]) * k
```

`k` runs from 0 to 1 over 0.16 s; each piece is drawn at `start + (end - start) * k`, sliding past the other. When `k` reaches 1:

- If either piece is a Light Ball, or both are specials, it's a **combo** (lesson 6): spend a move and go to `clear`.
- Else if `resolve(...)` finds matches, spend a move and go to `clear`.
- Else **swap back**: restore the grid, reverse `from`, and play the same tween in the `unswap` phase, then return to `idle`. No move is spent.

`g.timer` is reset to 0 at every phase change, so each phase measures its own time.

### The intro phase

```js
if (g.phase === 'intro' && settled() && g.timer > 1.2) { g.phase = 'idle'; g.idleT = 0 }
```

The board starts in `intro`: input is ignored until every gem has landed and the level banner has had at least 1.2 s.

## Check your work

- Make swaps slower so you can watch them: change both `0.16`s to `0.6`.
- Make dragging more sensitive: change `> 14` to `> 6`.
- Drag-only controls: comment out the `if (released && g.press && !g.press.moved) { … }` block. Tapping no longer selects gems; dragging still swaps.
- Log every swap attempt: add `print('swap', a, b)` as the first line of `trySwap`, and watch the Console as you play.
