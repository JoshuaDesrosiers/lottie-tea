# 2. The shared library

**Goal:** understand the ~90 lines every Crown Match scene runs first, since everything else builds on them.

**What you'll learn**

- Two lifetimes of state: per **session** and per **screen**, both in `ctx.globals`.
- Loading and saving progress with `ctx.storage`.
- Caching refs across frames.
- An immediate-mode button with `ctx.tap`.
- Seeded random numbers, and generating 20 levels from a formula.

## The code

This is the top of `demo_match3.js`, verbatim. Open any of the three scene scripts in **Code** mode and you'll see it at the top.

```js title="demo_match3.js — shared library"
// ===================================================================
//  CROWN MATCH — a royal match-3. Three scenes, each one Code program:
//  Home, Levels (the kingdom map) and Game (the board). Shared library
//  first; Rust appends one `//@program` section per scene.
//
//  ctx.globals.match3  — this play session (the level picked, the save)
//  ctx.globals.m3scene — the current screen's cached refs (cleared on
//                        every scene switch: leaving restores the pose)
//  ctx.storage 'crownmatch' — progress: unlocked level, best stars per
//                        level, coins. Survives restarts.
// ===================================================================

const S = ctx.globals.match3 || (ctx.globals.match3 = {})
const g = ctx.globals.m3scene || (ctx.globals.m3scene = {})
const save = S.save || (S.save = Object.assign({ unlocked: 1, stars: {}, best: {}, coins: 0 }, ctx.storage.get('crownmatch') || {}))
function persist() { ctx.storage.set('crownmatch', save) }
const T = performance.now() / 1000
const dt = Math.min(ctx.deltaSeconds, 1 / 20)
const keys = ctx.keysDown
const LEVEL_COUNT = 20

if (!g.refs) { g.refs = {}; g.mouseWas = true }
const ref = (id) => {
  let r = g.refs[id]
  if (r === undefined) { r = getCompByID(id); g.refs[id] = r }
  return r
}
function setText(id, text) { const r = ref(id); if (r && r.textContent !== text) r.textContent = text }
function show(id, on) { const r = ref(id); if (r && r.visible !== on) r.visible = on }

/** A plate button: grows on hover, returns true when tapped. */
function button(id, x, y, w, h, enabled = true) {
  const btn = ref(id + 'Btn')
  if (!btn) return false
  const over = enabled && Math.abs(ctx.mouseX - x) < w / 2 && Math.abs(ctx.mouseY - y) < h / 2
  const s = over ? (keys.has('mouse') ? 0.95 : 1.06) : 1
  if (btn.scaleX !== s) { btn.scaleX = s; btn.scaleY = s }
  return over && ctx.tap
}

function go(scene) {
  ctx.globals.m3scene = {}
  ctx.loadScene(scene)
}

const GEM_COLORS = [
  [0.93, 0.18, 0.3, 1], [0.18, 0.5, 1, 1], [0.18, 0.82, 0.36, 1],
  [1, 0.8, 0.16, 1], [0.7, 0.34, 0.98, 1], [1, 0.5, 0.12, 1], [1, 1, 1, 1],
]
const totalStars = () => Object.values(save.stars).reduce((a, b) => a + b, 0)

/** Deterministic random numbers, so each level always has the same layout. */
function rng(seed) {
  let a = seed >>> 0
  return () => {
    a = (a + 0x6d2b79f5) >>> 0
    let t = a
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}

/** Level `n` (1-based): moves, goals, frost layout, holes, star scores. */
function levelDef(n) {
  const r = rng(n * 7919 + 13)
  const colors = n <= 3 ? 5 : 6
  const order = [0, 1, 2, 3, 4, 5].slice(0, colors).sort(() => r() - 0.5)
  const goals = []
  const goalCount = n < 4 ? 1 : n < 11 ? 2 : 3
  for (let k = 0; k < goalCount; k++) goals.push({ t: order[k], n: 10 + Math.floor(n * 1.3) + Math.floor(r() * 5) })
  // Frost: every other level from 5, in one of three patterns.
  const frost = new Array(64).fill(0)
  if (n >= 5 && n % 2 === 1) {
    const pattern = Math.floor(n / 2) % 3
    for (let rr = 0; rr < 8; rr++) for (let c = 0; c < 8; c++) {
      const on = pattern === 0 ? rr >= 2 && rr <= 5 && c >= 2 && c <= 5 : pattern === 1 ? rr === 3 || rr === 4 || rr === 6 : (rr + c) % 3 === 0 && rr > 1
      if (on) frost[rr * 8 + c] = n >= 11 ? 2 : 1
    }
    const total = frost.reduce((a, b) => a + (b > 0 ? 1 : 0), 0)
    if (goals.length === 3) goals.pop()
    goals.push({ t: 'frost', n: total })
  }
  // Holes: every 5th level gets a shaped board.
  const holes = new Array(64).fill(false)
  if (n % 5 === 0) for (const [rr, c] of [[0, 0], [0, 1], [1, 0], [0, 7], [0, 6], [1, 7], [7, 0], [7, 7], [3, 3], [3, 4], [4, 3], [4, 4]]) holes[rr * 8 + c] = true
  const moves = Math.max(15, 27 - Math.floor(n * 0.55)) + (frost.some((f) => f) ? 5 : 0)
  const base = 6000 + n * 700
  return { n, colors, goals, frost, holes, moves, stars: [Math.round(base * 0.45), Math.round(base * 0.75), base] }
}
```

## How it works

### Two lifetimes in `ctx.globals`

`ctx.globals` is one plain object that survives scene switches and is wiped when Playground starts. Crown Match hangs two objects off it:

```js
const S = ctx.globals.match3 || (ctx.globals.match3 = {})
const g = ctx.globals.m3scene || (ctx.globals.m3scene = {})
```

- **`S`** ("session") holds things that must cross scenes: the level you picked on the map (`S.level`) and the loaded save (`S.save`).
- **`g`** ("this screen") holds the current scene's working state: cached refs, the board, timers. The `go()` helper replaces it with a fresh `{}` just before every `ctx.loadScene`, so each screen starts clean.

The `x || (x = {})` idiom means "use it if it exists, otherwise create it now". The first frame creates it; every later frame reuses it.

### The save file

```js
const save = S.save || (S.save = Object.assign({ unlocked: 1, stars: {}, best: {}, coins: 0 }, ctx.storage.get('crownmatch') || {}))
function persist() { ctx.storage.set('crownmatch', save) }
```

`ctx.storage` is persistent key/value storage (the browser's local storage under the hood): it survives page reloads and editor restarts. `ctx.storage.get('crownmatch')` returns the saved object, or `null` the first time. `Object.assign` lays it over the defaults, so a save from an older version that lacks a field still gets the default. The result is loaded once per session into `S.save`; `persist()` writes it back when a level is won (lesson 7). See [Storage API](../../scripting/storage-api.mdx).

### A frame clock and a capped `dt`

```js
const T = performance.now() / 1000
const dt = Math.min(ctx.deltaSeconds, 1 / 20)
```

`T` is a free-running clock in seconds, used for things that should keep moving whatever the state (bobbing, pulsing, hint wiggles). `dt` is this frame's duration, capped at 1/20 s so a hiccup can't make a gem jump half the board.

### Cached refs

```js
if (!g.refs) { g.refs = {}; g.mouseWas = true }
const ref = (id) => {
  let r = g.refs[id]
  if (r === undefined) { r = getCompByID(id); g.refs[id] = r }
  return r
}
```

The Game scene looks up hundreds of nodes per frame. `ref(id)` looks each one up once and keeps the ref in `g.refs` for the rest of the screen's life. A ref stays valid across frames: writes through it go to the engine, and its world-position reads come from the current frame. (Its `x`, `y` and so on read back what the script last wrote, which is exactly what this script needs since it owns those nodes.) The cache is dropped with `g` on every scene switch, because the next scene has different nodes.

`g.mouseWas = true` is a small guard: it pretends the mouse was already down when a screen starts, so the click that *opened* this screen can't count as a press on it.

### Tiny write-if-changed helpers

```js
function setText(id, text) { const r = ref(id); if (r && r.textContent !== text) r.textContent = text }
function show(id, on) { const r = ref(id); if (r && r.visible !== on) r.visible = on }
```

Both skip writes that wouldn't change anything. Every write is a call into the engine, and changing a text re-lays out its glyphs, so this matters with dozens of labels.

### Immediate-mode buttons

```js
function button(id, x, y, w, h, enabled = true) {
  const btn = ref(id + 'Btn')
  if (!btn) return false
  const over = enabled && Math.abs(ctx.mouseX - x) < w / 2 && Math.abs(ctx.mouseY - y) < h / 2
  const s = over ? (keys.has('mouse') ? 0.95 : 1.06) : 1
  if (btn.scaleX !== s) { btn.scaleX = s; btn.scaleY = s }
  return over && ctx.tap
}
```

Call it every frame with the button's rectangle; it grows the plate on hover, shrinks it while pressed (`'mouse'` is in `ctx.keysDown` while any button is held), and returns `true` on the frame it's tapped. Usage reads naturally: `if (button('play', 0, -90, 200, 64)) { … }`. `ctx.tap` works for mouse clicks and finger taps alike.

:::info UI Button components
Toasty also has a **UI Button** component (with `ref.clicked`, hover and pressed colours) that does this without code. Crown Match hand-rolls its buttons to control the exact feel. See [UI controls](../../components/ui-controls.mdx).
:::

### Scene switching

```js
function go(scene) {
  ctx.globals.m3scene = {}
  ctx.loadScene(scene)
}
```

Reset the per-screen state, then ask for the switch (which happens after this frame).

### Seeded randomness and the level generator

`rng(seed)` is a tiny seeded pseudo-random generator (the "mulberry32" algorithm): the same seed always gives the same sequence. `levelDef(n)` seeds it with the level number, so level 7 always has the same goals and frost pattern, without storing 20 level files:

| Field | Rule |
|---|---|
| `colors` | 5 gem colours for levels 1–3, then 6. |
| `goals` | 1 goal below level 4, 2 below level 11, then 3. Each: collect `10 + 1.3n + (0..4)` gems of a shuffled colour. |
| `frost` | From level 5, odd levels get frost in one of three patterns; from level 11 it's double-thick (`2`). A frost level swaps its last goal for "break all the frost". |
| `holes` | Every 5th level cuts 12 cells out of the board (corners and centre). |
| `moves` | `max(15, 27 - 0.55n)`, plus 5 on frost levels. |
| `stars` | Score thresholds at 45 %, 75 % and 100 % of `6000 + 700n`. |

## Check your work

Make one change at a time in the **Game** script (the library is copied into each scene's program, so edit the scene you're testing), play, and undo it:

- In `levelDef`, change `const moves = …` to `const moves = 99`. Level 1 now shows 99 moves.
- Make every level frosty: change `if (n >= 5 && n % 2 === 1)` to `if (true)`. Level 1 gets frost and a "BREAK … FROST" goal.
- Add `if (ctx.tap) print(JSON.stringify(save))` at the end of the **Home** script, win a level, go home and tap: the Console shows `unlocked`, `stars`, `best` and `coins`.
