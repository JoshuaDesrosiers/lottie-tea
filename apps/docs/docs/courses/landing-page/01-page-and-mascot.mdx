# 1. The page and the mascot

In this course you build the landing page for **Crumb**, a meal-planning app, one section per lesson. By the end it uses five Toasty Lite components together, each doing one job:

| Component | Where | Job |
|---|---|---|
| `toasty` | Header logo | A mascot that blinks, hops on hover and squashes on click |
| `theme` | Header | Switches the page between light and dark |
| `arrow` | Hero buttons | Slides forward when its link is hovered or focused |
| `status` | Signup form | Shows loading, success and error on the submit button |
| `bell` | Header | Rings and shows an unread badge for notifications |

All five load from one runtime, share one animation loop, and pause when they scroll out of view. You don't build the components here; you use the shipped files. The [animated like button](../animated-like-button/01-draw-the-heart.mdx) and [icon system](../icon-system/01-design-rules.mdx) courses show how files like these are made, and **+ → Templates** in the editor has every one of them (for example **Lite: Toasty mascot**) if you want to open and restyle one.

**Goal of this lesson:** the header and hero, with the mascot as the logo.

## Steps

1. Put the runtime and the component files in your static folder:

```text
public/toasty/an1mbyt3-lite.js
public/toasty/an1mbyt3-runtime.js
public/toasty/lite/toasty.json
public/toasty/lite/theme.json
public/toasty/lite/arrow.json
public/toasty/lite/status.json
public/toasty/lite/bell.json
```

2. Load the runtime once, in the page's `<head>`:

```html
<script type="module" src="/toasty/an1mbyt3-lite.js"></script>
```

3. Build the header and hero. The live frame below loads the runtime for you, so its HTML starts at `<header>`.

## How it works

- **The mascot needs no code.** The `toasty` file handles its own pointer: Pointer Listeners set its `hover` input, so it hops and blushes, and its On Click fires the `boop` trigger, which squashes it. While idle it blinks and breathes on a loop. It has no `ink` property; its colours are its own.
- **Size it with CSS.** Every Lite component draws its 96 × 96 scene into whatever box you give it. `width: 44px; height: 44px` on the element is all it takes. It tracks the device pixel ratio, so it stays sharp on high-density screens.
- **Design tokens.** The frame provides `--ink`, `--muted`, `--line`, `--surface`, `--page` and `--accent`, with dark values under `:root[data-theme="dark"]`. Everything on the page uses them, which is what makes the theme switch in the next lesson a one-line change.
- **The canvas is decorative.** The link carries `aria-label="Crumb home"`, so a screen reader announces the link, not the animation.

## Check your work

- The mascot blinks every few seconds, hops when you hover it, and squashes when you click it.
- Below 560 px wide, the nav links hide and the header still fits.
