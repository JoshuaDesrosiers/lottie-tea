# 3. Arrow calls to action

**Goal:** two calls to action under the hero text. Each ends with the `arrow` icon, which slides forward and redraws its shaft when the link is hovered or focused, not only when the pointer is over the arrow itself.

## Steps

1. Add the two links with an arrow in each. `ink="currentColor"` makes the arrow white on the filled button and ink-coloured on the outlined one.
2. Connect each link to its arrow with the `hoverInput` helper from lesson 2.

function hoverInput(el, icon) {
  const set = (value) => { if (icon.player) icon.player.setInput('hover', value) }
  el.addEventListener('pointerenter', () => set(true))
  el.addEventListener('pointerleave', () => set(false))
  el.addEventListener('focus', () => set(true))
  el.addEventListener('blur', () => set(false))
}

// Theme switch: the page owns the theme, the icon shows it.
const root = document.documentElement
const themeButton = document.querySelector('.theme')
const themeIcon = themeButton.querySelector('toasty-lite')
let dark = root.dataset.theme === 'dark'

function applyTheme() {
  root.dataset.theme = dark ? 'dark' : 'light'
  themeButton.setAttribute('aria-pressed', String(dark))
  themeIcon.setAttribute('inputs', JSON.stringify({ dark: dark }))
}
themeButton.addEventListener('click', () => { dark = !dark; applyTheme() })
hoverInput(themeButton, themeIcon)
applyTheme()

// Arrows follow their link's hover and focus.
for (const cta of document.querySelectorAll('.cta')) {
  hoverInput(cta, cta.querySelector('toasty-lite'))
}`}

## How it works

- **The link is the hover target.** `arrow` has its own Pointer Listeners, but here the icon has `pointer-events: none`, and the link sets `hover`. The whole pill reacts, which is what users expect from a button.
- **Focus counts as hover.** Keyboard users see the same motion when they Tab onto a link, because `hoverInput` also listens for `focus` and `blur`.
- **One file, two looks.** Both arrows are the same `arrow.json`. `currentColor` resolves to white inside `.cta.primary` and to `--ink` inside `.cta.secondary`, and the secondary one follows the theme switch automatically.
- **The animation.** On hover the arrow group moves 10 units forward while the shaft's Trim start jumps to 0.6 and eases back to 0, so the line seems to be drawn from behind as it moves. Leaving crossfades back over 0.25 s.

## Check your work

- Hovering anywhere on either pill moves its arrow; the other arrow stays still.
- Tabbing through the page moves each arrow in turn.
- In dark mode, the secondary arrow turns light with the text.
