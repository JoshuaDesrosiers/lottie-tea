# 4. A signup form

**Goal:** a waitlist form. Pressing **Join the waitlist** shows a spinning ring on the button while the request runs, then a green check if it worked or a red cross with a shake if it didn't. A message under the field says the same thing in words.

The `status` icon has one input, an Enum named `status`, with four values:

| Value | Shows |
|---|---|
| `idle` | Nothing |
| `loading` | A spinning trim-path arc (loops) |
| `success` | The ring closes, a green disc pops, a white check draws on |
| `error` | A red disc, a white cross draws on, and a shake |

## Steps

1. Add the form. The icon sits inside the submit button, after its label.
2. Add the submit handler. One `setStatus` function updates the icon, a `data-status` attribute for CSS, and the status message together.

Try it with any address. To see the error path, use `maya@northwind.app`, which the stand-in server treats as already registered, or submit an empty field.

// Stand-in for your API: rejects an address that is already registered.
const registered = ['maya@northwind.app']
function joinWaitlist(address) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (registered.includes(address.toLowerCase())) reject(new Error('That address is already on the waitlist.'))
      else resolve()
    }, 1200)
  })
}

  event.preventDefault()

    setStatus('error', 'Enter an email address, like name@example.com.')
    email.focus()

  setStatus('loading', 'Saving your spot...')

    label.textContent = 'Joined'

## How it works

- **One input, four states.** Every value of `status` has its own state, and every state can reach every other directly, so the page can jump from `loading` to `error` or from `error` back to `idle` at any time. Transitions back to `idle` crossfade for 0.25 s; the others start instantly.
- **`loading` loops until you change it.** The page doesn't need to know how long the request takes. When it settles, set `success` or `error` and the icon finishes from wherever the spinner was.
- **The words matter more than the icon.** The `<p role="status" aria-live="polite">` announces each message to screen readers. The icon is decoration on top.
- **The button is disabled while loading** so a double click can't submit twice, and stays disabled after success. After an error it is enabled again, and typing in the field returns the icon to `idle`.
- **The ring follows the button text.** `ink="currentColor"` gives the spinner the button's text colour, which flips with the theme because the button uses `--ink` and `--page`.
- **Replace `joinWaitlist`** with your real request. Resolve for success, reject with an `Error` whose message is safe to show.

## Check your work

- A valid new address shows the spinner for about a second, then the check and the success message.
- `maya@northwind.app` shows the red cross, the shake and the message "That address is already on the waitlist."
- After an error, typing in the field clears the cross.
