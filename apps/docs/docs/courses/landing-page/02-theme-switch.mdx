# 2. A theme switch

**Goal:** a button in the header that switches the whole page between light and dark. The `theme` icon inside it plays the sun-to-moon animation.

## Steps

1. Add an actions area to the header with a `<button>` around the icon. The icon gets `pointer-events: none`: the button handles every click and key press.
2. Add the JavaScript. A small `hoverInput` helper connects a button's hover and focus to an icon's `hover` input; you reuse it for every icon in this course.

  js={`// Pointer and keyboard focus both count as hover for an icon.
function hoverInput(el, icon) {
  const set = (value) => { if (icon.player) icon.player.setInput('hover', value) }
  el.addEventListener('pointerenter', () => set(true))
  el.addEventListener('pointerleave', () => set(false))
  el.addEventListener('focus', () => set(true))
  el.addEventListener('blur', () => set(false))
}

// Theme switch: the page owns the theme, the icon shows it.
const root = document.documentElement
const themeButton = document.querySelector('.theme')
const themeIcon = themeButton.querySelector('toasty-lite')
let dark = root.dataset.theme === 'dark'

function applyTheme() {
  root.dataset.theme = dark ? 'dark' : 'light'
  themeButton.setAttribute('aria-pressed', String(dark))
  themeIcon.setAttribute('inputs', JSON.stringify({ dark: dark }))
}
themeButton.addEventListener('click', () => { dark = !dark; applyTheme() })
hoverInput(themeButton, themeIcon)
applyTheme()`}

## How it works

- **The page owns the theme.** The button's click flips `dark`, writes `data-theme` on `<html>` and sets the icon's `dark` input. Every CSS token switches with `data-theme`, so the whole page changes at once.
- **The icon starts in the right state.** `applyTheme()` runs once at load and sets `inputs` before the icon has loaded. The element reads the attribute when it starts, so a page that opens in dark mode shows the moon without playing the animation.
- **`aria-pressed`** tells assistive technology that this is a toggle and whether it is on. The label stays "Dark mode" in both states, which is the recommended pattern for toggle buttons.
- **Hover through the player.** `hoverInput` calls `icon.player.setInput('hover', …)` directly instead of rewriting the `inputs` attribute, so it never overwrites the `dark` value the attribute carries. `player` is set once the icon is ready; before that, a hover is simply skipped.
- **Remembering the choice.** On your own site, save the choice so it survives a reload, and read it before the first paint to avoid a flash:

```js
// In applyTheme(), after setting data-theme:
try { localStorage.setItem('crumb.theme', dark ? 'dark' : 'light') } catch {}

// At startup, before the first applyTheme():
let saved = null
try { saved = localStorage.getItem('crumb.theme') } catch {}
let dark = saved ? saved === 'dark' : matchMedia('(prefers-color-scheme: dark)').matches
```

The live example leaves this out so it always starts in the docs' current theme.

## Check your work

- Clicking the icon switches the frame's page between light and dark, and the icon animates each time.
- Tab to the button and press Space: the same happens, and a focus ring shows.
- Switching the docs theme resets the frame to match.
