# Courses

Each course builds one real thing from an empty scene to a file running in a web page. The lessons are short. Every lesson states its goal, gives you exact steps and values, shows the complete code, explains how it works, and ends with a check you can run yourself.

The courses use the same ten [Toasty Lite components](../use-cases/index.mdx) and the same small game you can see elsewhere in these docs. Every finished result is also in the editor under **+ → Templates** (for example **Lite: Like heart** or **Game: Toast Catch**), which adds it to your project as its own scene, so you can compare your work with it at any point.

## The four courses

| Course | You'll ship | Audience | Time |
|---|---|---|---|
| [Animated like button](./animated-like-button/01-draw-the-heart.mdx) | The `heart` component, built by hand: line art, a trim-path burst, a state machine with hover, a theme-aware `ink` colour, exported to Toasty Lite and running inside a real `<button aria-pressed>` in HTML and React. | Designers and front-end developers new to Toasty | 60–90 min |
| [Animated icon system](./icon-system/01-design-rules.mdx) | A consistent set of three interactive icons (menu, theme, copy) that share one grid, one stroke, one hover behaviour and one colour property. Covers trim paths, path morphs and trigger-driven feedback. | Anyone who finished the like button course | 60 min |
| [Toast Catch from scratch](./toast-catch-from-scratch/01-the-scene.mdx) | A complete arcade game in the full engine: shapes, one Code program, game state, input, an object pool, collisions, score and lives, sound and game over. Embedded on a page with a live React score panel. | Developers comfortable with basic JavaScript | 90 min |
| [Product landing page](./landing-page/01-page-and-mascot.mdx) | A full landing page that uses five Lite components together: a mascot in the header, a theme switch wired to the page theme, arrow calls to action, a signup form with a status icon and a notification bell. Finished as plain HTML and as a React port. | Front-end developers | 60 min |

Take the like button course first if you have never used the editor. The icon system course assumes you can already draw, animate and wire a component. The game course and the landing page course stand on their own.

## What you need

- The editor at [toastycreate.web.app](https://toastycreate.web.app), or the desktop app. See [Web and desktop](../getting-started/web-and-desktop.mdx).
- For the web lessons: any static site or local dev server, plus the Lite runtime files. [Toasty Lite](../runtimes/lite.mdx) explains where they come from and where to put them.
- For the game course: the engine export. [Export for web](../embedding/export-for-web.mdx) covers the files.

## Conventions in these courses

- Editor labels are written in **bold**, exactly as they appear on screen. A path such as **+ → Import → SVG…** means: open the **+** menu, then **Import**, then **SVG…**.
- Values come straight from the shipped components and game, so your result can match ours exactly. Scene coordinates have the origin in the middle and **y pointing up**.
- Web examples reference the runtime and files at `/toasty/an1mbyt3-lite.js` and `/toasty/lite/<name>.json`, the paths your own site would use.
- Every live example runs in a sandboxed frame below its source. Use the **Reload** button in the frame's address bar to start it over.
