# ctx reference

The complete list, alphabetical, with one-line descriptions and a link to the page with details, parameters and examples. "Low-level" members take internal node ids (`ctx.nodes[i].id`) and exist so refs can be built; use the ref form instead.

Two playgrounds to try members from the tables below. The first one reads `ctx`; the buttons under the stage set an input and a Property the way a page would.

<ScriptLab
  title="ctx playground"
  code={`// Try any ctx member here. Live values go to the label;
// press space (after clicking the stage) to log a snapshot.
const g = ctx.globals.pg || (ctx.globals.pg = { was: false })
ctx.props.message = ctx.state + '  t=' + ctx.time.toFixed(1) + '  mouse ' + Math.round(ctx.mouseX) + ', ' + Math.round(ctx.mouseY)

## Helpers

Always in scope as bare names. They also form the vocabulary that Nodes-to-Code conversion emits (see [Blocks](./blocks.mdx)).

| Helper | Returns |
|---|---|
| `add(a, b)`, `subtract(a, b)`, `multiply(a, b)` | the arithmetic result |
| `divide(a, b)` | `a / b`, or `0` when `b` is `0` |
| `greaterThan(a, b)`, `lessThan(a, b)`, `equals(a, b)` | `1` or `0` |
| `and(a, b)`, `or(a, b)` | `1` or `0` (non-zero = true) |
| `not(a)` | `1` if `a` is `0`, else `0` |
| `select(cond, a, b)` | `a` if `cond` is non-zero, else `b` |
| `lerp(a, b, t)` | `a + (b - a) * t`, with `t` clamped to 0..1 |
| `clamp(v, min, max)` | `v` limited to the range (min/max may be given in either order) |
| `random(seed)` | a repeatable value in 0..1 for an integer seed (same hash as the Nodes Random node) |

## Ref members

`R` = readable, `W` = writable, `fn` = method.

The second playground is for ref members. Swap `ball` and `player` for any id in the scene:

<ScriptLab
  title="Ref playground"
  code={`// Try any ref member here. Space kicks the ball.
const g = ctx.globals.rp || (ctx.globals.rp = { was: false })
const player = getCompByID('player')
const ball = getCompByID('ball')
player.rotation += 90 * ctx.deltaSeconds
player.fillColor = [0.96, 0.55 + Math.sin(ctx.time * 3) * 0.3, 0.15, 1]

  print(player.id, 'at', Math.round(player.worldX), Math.round(player.worldY), '| rotation:', Math.round(player.rotation))

g.was = space`}

| Type | Shape |
|---|---|
| Colour | `[r, g, b, a]`, each 0..1 |
| 2D vector | `{ x, y }` (velocity also accepts `[x, y]`) |
