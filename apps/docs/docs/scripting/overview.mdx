# Scripting overview

Toasty games are scripted in **plain JavaScript**. A script is a short program attached to a **state** in a scene's state machine. While that state is active, the script runs once every frame. It reads the world through one object, `ctx`, and changes it through **refs**: small objects you get back from `getCompByID('player')` whose properties (`x`, `y`, `rotation`, `visible`, `textContent`, ...) you simply assign.

```js
// A state's Code program. Runs every frame while the state is active.
const player = getCompByID('player')
const speed = 200
if (ctx.keysDown.has('right')) player.x += speed * ctx.deltaSeconds
if (ctx.keysDown.has('left'))  player.x -= speed * ctx.deltaSeconds
```

That is the whole model. The rest of this section is reference.

## Three ways to program a state

Every state can be a **Programmable State**. Its program is one of three kinds, picked with the tabs at the top of the program editor:

| Tab | What it is | Runs where |
|---|---|---|
| **Code** | JavaScript, the subject of this section | Playground, the State Machine tab with **Run Programs** on, exported games and website embeds |
| **Nodes** | A dataflow graph (math nodes wired into Set Property nodes) | Everywhere |
| **Blocks** | Scratch-style blocks (when key pressed, forever, wait, ...) | Everywhere |

Nodes and Code convert into each other for simple programs. Blocks are their own language; see [Blocks](./blocks.mdx).

## Where you write code

- **Inline, in the state.** Turn on **Programmable State** for a state in the state machine's side column, double-click the state's box on the graph, and pick the **Code** tab.
- **In a project file.** In the **Code** mode (the IDE view), create a `.js` file under your project's files, then point the state at it: in the state's Code tab, the **Runs** dropdown lists every `.js` file. The state then stores `@file:Scripts/player.js` instead of inline text and runs that file.

<Shot id="scripting-code-tab" caption="A Programmable State's Code tab, with the Runs picker and Monaco editor" />

The editor is Monaco (the VS Code editor). Typing `ctx.` suggests the core members, and inside `getCompByID('` it suggests every node id in the scene; inside `getCompByClass('` it suggests every class.
