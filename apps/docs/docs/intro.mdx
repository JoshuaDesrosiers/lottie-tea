# Introduction

**ToastyCreate** ("Toasty") is an editor for interactive graphics. It runs in the browser at [toastycreate.web.app](https://toastycreate.web.app/) and as a desktop app. You draw vector art or import images, animate them on a timeline, connect the animations with a state machine, and ship the result to the web.

## Two runtimes

What you make in the editor can run on the web in one of two ways:

| | Toasty Lite | Toasty engine |
|---|---|---|
| For | UI animation: icons, buttons, toggles, loaders, illustrations | Games and rich interactive scenes |
| What it plays | A JSON file (Export → Animation → Toasty Lite) | A `.teab` game file (Export → Game → Website embed) |
| Size | About 25 KB of JavaScript | About 25 MB (wasm engine) |
| Per page | As many as you like | One at a time |
| Features | Vector shapes, gradients, strokes, trim paths, path morphs, keyframes, state machines, hover and click actions, properties | Everything: scripts, physics, particles, lights, audio, post effects, 3D |
| Use it from | `<toasty-lite>`, JavaScript, React | `<an1-player>`, JavaScript, React |

Read [Lite or engine?](./runtimes/lite-vs-engine.mdx) for a decision guide.

## The building blocks

- A **project** holds one or more **scenes**. A scene is a tree of **nodes**: shapes, text, images, groups and cameras, plus 3D objects in the engine.
- **Components** give nodes abilities. Examples: a UI Button, so the pointer can hit-test the node; Pointer Listeners, for hover and press actions; a Stroke Style, for dashes and trim paths; a Rigidbody, a Particle System or a Light, for the engine.
- **Animations** are keyframes on a timeline. A **state machine** picks which animation plays based on **inputs** (booleans, numbers, enums and triggers), and crossfades between them.
- **Properties** are a scene's named values. Text, colours and positions can be bound to them, and the page embedding the scene can set them.
- In the engine, each state can also run a **Code program**: JavaScript that runs every frame with a `ctx` object for input, time, physics, sound and data.
