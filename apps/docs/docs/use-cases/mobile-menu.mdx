# Mobile menu

On narrow screens the navigation folds into a single button. The icon carries the meaning of that button: three bars say "there is more", the cross says "this closes it". This page uses the `menu` component in a real site header. Below the breakpoint the links collapse, the button appears, and opening it slides the navigation down under the header.

  js={`const button = document.querySelector('.menu-button')
const icon = button.querySelector('toasty-lite')
const nav = document.querySelector('#site-nav')

let open = false

function setOpen(next, { returnFocus = false } = {}) {
  open = next
  button.setAttribute('aria-expanded', String(open))
  nav.classList.toggle('is-open', open)
  icon.player?.setInput('open', open)
  if (!open && returnFocus) button.focus()
}

icon.addEventListener('toasty:ready', () => icon.player.setInput('open', open))
button.addEventListener('click', () => setOpen(!open))

// Close on Escape, on a link click, and when clicking outside the header.
document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape' && open) setOpen(false, { returnFocus: true })
})
nav.addEventListener('click', (e) => {
  if (e.target.closest('a')) setOpen(false)
})
document.addEventListener('click', (e) => {
  if (open && !e.target.closest('.site-header')) setOpen(false)
})

// Forward hover so the bars lift a little, as they do on their own.
button.addEventListener('pointerenter', () => icon.player?.setInput('hover', true))
button.addEventListener('pointerleave', () => icon.player?.setInput('hover', false))

// If the window grows past the breakpoint, reset the menu.
matchMedia('(min-width: 901px)').addEventListener('change', (e) => {
  if (e.matches) setOpen(false)
})`}

export function SiteHeader({ ink = '#18181b' }) {

## How it works

### One button, one source of truth

```html
<button class="menu-button" type="button" aria-expanded="false" aria-controls="site-nav">
  <toasty-lite src="/toasty/lite/menu.json" ink="currentColor"></toasty-lite>
  <span class="visually-hidden">Menu</span>
</button>
```

The `open` variable in the script is the only state. `setOpen()` writes it to three places at once:

| Where | What changes |
|---|---|
| `aria-expanded` on the button | Screen readers announce "Menu, collapsed" or "expanded" |
| `.is-open` on the nav | The CSS slides the panel down and makes it visible |
| The `open` input | The animation plays `Closed` → `Open`: the top and bottom bars rotate into a cross and the middle bar trims to its centre |

Because the page sets `open` explicitly every time, the icon can never disagree with the panel. That's also why the canvas has `pointer-events: none`: the `menu` file toggles `open` on its own when clicked, and you don't want two things toggling the same value. See [Like button](./like-button.mdx#why-the-canvas-has-pointer-events-none) for the details.

The label stays "Menu" in both states. The button's role doesn't change when it opens, only its expanded state, and `aria-expanded` already says that.

### The nav is the same element at every width

There's only one `<nav>`. Above 900 px it's an inline row of links. Below, the media query positions it under the header and hides it with `visibility: hidden`, which also removes the links from the tab order while the menu is closed. No duplicate markup for mobile.

### Closing

The menu closes on Escape (and returns focus to the button, so keyboard users aren't stranded), on a link click, on a click outside the header, and when the window grows past the breakpoint. Each path calls `setOpen(false)`, so the icon animates back to the bars every time. The return trip crossfades over 0.28 s.

### Inputs used

| Name | Kind | Notes |
|---|---|---|
| `open` | Bool input | `Closed` / `Open` on the base layer |
| `hover` | Bool input | The `Hover` layer scales the bars to 1.08 |
| `ink` | Color Property | Bound to all three bars |

## React

The React tab is the same header. `inputs={{ open, hover }}` is diffed on each render, so the animation receives `open` exactly when the state changes. In these docs you can try the button on its own with `<Lite>`:

```jsx live
function MenuButton() {
  const [open, setOpen] = React.useState(false)
  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 12 }}>
      <button
        type="button"
        aria-expanded={open}
        onClick={() => setOpen(!open)}
        style={{ display: 'grid', placeItems: 'center', width: 44, height: 44, padding: 0, border: '1px solid var(--t-line)', borderRadius: 10, background: 'transparent', color: 'inherit', cursor: 'pointer' }}
      >
        <Lite src="menu" ink="auto" inputs={{ open }} style={{ width: 40, height: 40, pointerEvents: 'none' }} />
        <span style={{ position: 'absolute', width: 1, height: 1, overflow: 'hidden', clip: 'rect(0 0 0 0)' }}>Menu</span>
      </button>
      <span>{open ? 'Menu open' : 'Menu closed'}</span>
    </div>
  )
}
```

## Make it yours

- **Start from the template.** In the editor, **Add → Templates → Lite: Menu ↔ close** opens this exact `menu` component as a new scene. Restyle it (colours, stroke widths, timing, shapes), keep the input and Property names, then use **Export → Animation → Toasty Lite (.json)** and replace `/toasty/lite/menu.json` with your file. The page code on this page works unchanged.
- **Colour and weight.** The bars follow `ink`, so they take the button's `color`. Bar thickness is part of the file; change the stroke width in the editor and re-export.
- **Breakpoint.** Change `900px` in the CSS and `901px` in the `matchMedia` call together.
- **A drawer instead of a dropdown.** Keep the script and change only the CSS: position the nav `fixed` on the right edge and slide it with `transform: translateX(100%)`.
- **Your own icon.** The `menu` file is three strokes in a group with a `Closed` and an `Open` animation and a state machine on an `open` Bool. Build the same in the editor (a "kebab" that rotates, or a plus that turns into a minus), keep the input name, and export with **Export → Animation → Toasty Lite (.json)**. The page code doesn't change. See [Authoring for Lite](../runtimes/authoring.mdx).
