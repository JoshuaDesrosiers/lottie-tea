# Mascot

Empty states and error pages are where a product has the user's full attention and nothing to show them. A small character fills that gap: it softens a dead end, and it makes the next step (the one button on the page) more inviting. The `toasty` component is a slice of toast that breathes and blinks on its own, hops and blushes on hover, and squashes when it's clicked. This page puts it on an empty inbox and a 404, and shows how to cheer on a user through onboarding.

## How it works

### Toasty plays by itself

| State | Layer | When |
|---|---|---|
| `Idle` | Base | Always, looping every 3.6 s: a slow breath (a 1.5 % squash and stretch) and a blink near the end. |
| `Boop`, `Boop again` | Base | When the `boop` Trigger fires: a squash and stretch with the eyes squeezed shut. Two states alternate so repeated boops restart it. |
| `Calm`, `Happy` | `Face` | `hover` true: the face lifts, the mouth widens into a smile, the cheeks blush. |
| `Down`, `Up` | `Hop` | `hover` true: a small hop. |

Unlike the icons in the other use cases, Toasty keeps its own pointer handling here. It has no `pointer-events: none`, so pointing at it makes it hop (its Pointer Listeners set `hover`) and clicking it fires `boop` (its On Click action). That's fine because nothing on the page depends on those inputs. It's a picture you can poke, not a control.

The file has no `ink` Property. The crust, bread and face colours are fixed, and they read on light and dark pages.

### The page adds one connection

Both examples forward the hover and focus of the page's main action to the mascot:

```js
home.addEventListener('pointerenter', () => mascot.player?.setInput('hover', true))
home.addEventListener('pointerleave', () => mascot.player?.setInput('hover', false))
```

It's a small thing, but it ties the character to the one thing you want the user to do. On the empty inbox, clicking Check again also fires `boop`, so the button gets a reaction even when the answer is "no new mail".

### Boop needs `hover` to hold

`Boop` and `Boop again` return to `Idle` as soon as `hover` is `false`, with a 0.3 s crossfade. When the boop comes from Toasty's own click, the pointer is over it, so `hover` is `true` and the full squash plays. On the inbox, the click comes from Check again, which already set `hover` on pointer enter.

If you fire `boop` from code with nothing hovered, hold `hover` for the length of the boop:

```js
function cheer() {
  mascot.player?.setInput('hover', true)
  mascot.player?.fire('boop')
  setTimeout(() => mascot.player?.setInput('hover', false), 900)
}
```

### Accessibility

Toasty is decoration, so the element has `aria-hidden="true"`. The empty state's meaning is in the heading and text, and the actions are real buttons and links. The 404 page puts the requested path in the text, offers search, and links home and to support, so it's useful with the character removed.

## Onboarding

A mascot can also mark progress: a reaction each time the user finishes a setup step. This uses the `cheer()` pattern above. Tick the steps:

```jsx live
function Onboarding() {
  const mascot = React.useRef(null)
  const steps = ['Add your first store', 'Import products', 'Invite a teammate']
  const [done, setDone] = React.useState([false, false, false])
  const count = done.filter(Boolean).length

  function toggle(i) {
    const next = done.map((d, j) => (j === i ? !d : d))
    setDone(next)
    if (next[i] && mascot.current) {
      mascot.current.setInput('hover', true)
      mascot.current.fire('boop')
      setTimeout(() => mascot.current && mascot.current.setInput('hover', false), 900)
    }
  }

  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 20, flexWrap: 'wrap', padding: 16, border: '1px solid var(--t-line)', borderRadius: 14 }}>
      <Lite ref={mascot} src="toasty" style={{ width: 112, height: 112, flex: 'none' }} />
      <div style={{ flex: 1, minWidth: 200 }}>
        <strong>{count === steps.length ? 'You are all set' : 'Set up Northwind (' + count + ' of ' + steps.length + ')'}</strong>
        <ul style={{ listStyle: 'none', padding: 0, margin: '8px 0 0' }}>
          {steps.map((s, i) => (
            <li key={s} style={{ margin: '6px 0' }}>
              <label style={{ display: 'flex', alignItems: 'center', gap: 8, cursor: 'pointer' }}>
                <input type="checkbox" checked={done[i]} onChange={() => toggle(i)} />
                <span style={{ textDecoration: done[i] ? 'line-through' : 'none', color: done[i] ? 'var(--t-muted)' : 'inherit' }}>{s}</span>
              </label>
            </li>
          ))}
        </ul>
      </div>
    </div>
  )
}
```

The React tabs above capture the player with `onReady` and keep `hover` in `inputs`. A Trigger such as `boop` is an action, so it's fired on the player rather than passed as a prop.

## Make it yours

- **Start from the template.** In the editor, **Add → Templates → Lite: Toasty mascot** opens this exact `toasty` component as a new scene. Restyle it (colours, stroke widths, timing, shapes), keep the input and Property names, then use **Export → Animation → Toasty Lite (.json)** and replace `/toasty/lite/toasty.json` with your file. The page code on this page works unchanged.
- **Placement.** Keep the character to places with room and no urgency: empty states, 404s, success screens, onboarding. Leave it out of error messages that need action, such as a failed payment.
- **Size.** 112 to 160 px suits an empty state. Below about 64 px the face details stop reading.
- **Your own character.** Toasty is built from plain filled shapes in a `body` group (pivot at the feet), a `face` group, and three state machine layers. To make your brand's character, build the same structure in the editor: an `Idle` loop on the base layer, a `boop` Trigger with two alternating states, and `Face` and `Hop` layers on a `hover` Bool, with a UI Button and Pointer Listeners on an invisible hit shape. Export with **Export → Animation → Toasty Lite (.json)**, and every page on this site works with it unchanged. See [Authoring for Lite](../runtimes/authoring.mdx).
