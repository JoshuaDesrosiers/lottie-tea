# Call to action

The arrow after "Start free trial" is a promise that the link goes somewhere. A small push on hover makes the whole button feel responsive, and it's the kind of detail people notice only when it's missing. The `arrow` component slides forward and redraws its shaft from behind. It's built to be driven by the link around it, so the motion starts wherever the pointer enters the button, not only over the arrow.

## How it works

### The link drives the arrow

```js
link.addEventListener('pointerenter', () => arrow.player?.setInput('hover', true))
link.addEventListener('pointerleave', () => arrow.player?.setInput('hover', false))
```

`arrow` has a single Bool input, `hover`, and two states:

| State | What it draws |
|---|---|
| `Rest` | The arrow in place, shaft fully drawn. |
| `Over` | The arrow slides forward by about a tenth of its box while the shaft's trim start jumps to 0.6 and draws back to 0, so the line looks like it's being pulled from behind. |

The return to `Rest` crossfades over 0.25 s, so leaving the button mid-animation eases back instead of snapping.

The file has its own hover listeners on an invisible hit area, which is how it behaves when you drop it on a page by itself. That hit area covers only the canvas. Driving `hover` from the link makes the whole button the target, and `pointer-events: none` stops the canvas from setting `hover` a second time when the pointer crosses it.

### Same cue for keyboard users

`focus` and `blur` set the same input, so tabbing to a call to action shows the same movement as pointing at it. Because the link is a real `<a href>`, it's announced as a link with its text, opens in a new tab with a middle click, and works with JavaScript off (the arrow just won't move).

### Colour follows the button

`ink="currentColor"` gives each arrow its link's text colour: white on the orange primary button, the ink colour on the secondary buttons and the text link. Change a button's `color` and its arrow follows; in dark mode the secondary arrows switch with the text.

### Spacing

The arrow scene is 96 by 96, with the arrow in the middle third. The CSS gives the canvas 36 px so the arrow is a comfortable 13 px or so, then pulls it in with negative margins so the button's padding stays even. The canvas still has room for the forward slide, so nothing is clipped.

## React

The React tab is an `ArrowLink` component. `inputs={{ hover }}` sends the value when it changes. In these docs:

```jsx live
function ArrowLink() {
  const [hover, setHover] = React.useState(false)
  return (
    <a
      href="#"
      onClick={(e) => e.preventDefault()}
      onPointerEnter={() => setHover(true)}
      onPointerLeave={() => setHover(false)}
      onFocus={() => setHover(true)}
      onBlur={() => setHover(false)}
      style={{ display: 'inline-flex', alignItems: 'center', gap: 4, height: 42, padding: '0 16px', borderRadius: 10, background: 'var(--t-accent)', color: '#fff', fontWeight: 600, textDecoration: 'none' }}
    >
      Start 14-day trial
      <Lite src="arrow" ink="#ffffff" inputs={{ hover }} style={{ width: 36, height: 36, margin: '-10px -10px -10px -6px', pointerEvents: 'none' }} />
    </a>
  )
}
```

## Make it yours

- **Start from the template.** In the editor, **Add → Templates → Lite: Link arrow** opens this exact `arrow` component as a new scene. Restyle it (colours, stroke widths, timing, shapes), keep the input and Property names, then use **Export → Animation → Toasty Lite (.json)** and replace `/toasty/lite/arrow.json` with your file. The page code on this page works unchanged.
- **Other directions.** For a "Back" link, mirror the element with `transform: scaleX(-1)`. The motion mirrors with it, so the arrow pushes left.
- **External links.** For a link that opens another site, rotate the element by `-45deg` for a north-east arrow.
- **Weight.** Stroke width and cap are in the file. Change them on the `shaft` and `head` strokes in the editor to match your icon set, and re-export with **Export → Animation → Toasty Lite (.json)**.
- **Your own motion.** Keep a single `hover` Bool with `Rest` and `Over` states, and the page code here drives anything: a chevron that nudges, a plus that turns, an underline that draws on with trim end. See [Authoring for Lite](../runtimes/authoring.mdx).
