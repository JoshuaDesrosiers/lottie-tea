# Copy to clipboard

Copying gives the user nothing to look at: the text is already on screen, and the clipboard is invisible. The button has to confirm it. The `copy` component draws its two sheets out, draws a green check in, and returns to the copy icon by itself about 1.8 s later, so the page only has to fire one trigger. This page builds a developer settings screen with an API key field and two code snippets.

// Clipboard API first. Some embedded pages block it, so fall back to the
// older selection-based copy, which still works in most of them.
async function copyText(text) {
  try {
    await navigator.clipboard.writeText(text)
    return true
  } catch {}
  const area = document.createElement('textarea')
  area.value = text
  area.setAttribute('readonly', '')
  area.style.cssText = 'position:fixed;top:0;left:0;opacity:0'
  document.body.append(area)
  area.select()
  let ok = false
  try { ok = document.execCommand('copy') } catch {}
  area.remove()
  return ok
}

for (const button of document.querySelectorAll('.copy')) {
  const icon = button.querySelector('toasty-lite')
  const tip = button.querySelector('.tip')
  const what = button.getAttribute('aria-label').replace('Copy ', '')
  let timer = 0

  button.addEventListener('click', async () => {
    const source = button.dataset.copy && document.querySelector(button.dataset.copy)
    const text = button.dataset.secret || (source.value ?? source.textContent)
    const ok = await copyText(text)

    clearTimeout(timer)
    if (ok) {
      icon.player?.fire('copy')            // sheets out, check in, back by itself
      tip.textContent = 'Copied'
      announcer.textContent = what.charAt(0).toUpperCase() + what.slice(1) + ' copied'
    } else {
      tip.textContent = 'Press Ctrl+C to copy'
      if (source && source.select) source.select()
    }
    button.classList.add('is-copied')
    timer = setTimeout(() => {           // matches the icon's ~1.8 s
      button.classList.remove('is-copied')
      tip.textContent = 'Copy'
    }, 1800)
  })

  button.addEventListener('pointerenter', () => icon.player?.setInput('hover', true))
  button.addEventListener('pointerleave', () => icon.player?.setInput('hover', false))
}`}

## How it works

### One trigger, no cleanup

```js
icon.player?.fire('copy')
```

`copy` is a Trigger. Firing it moves the base layer from `Idle` to `Copied`, a 1.9 s animation that does the whole round trip:

1. The back and front sheets trim out (0 to 0.22 s).
2. A green check draws on (0.2 to 0.45 s).
3. The check trims away from its start (1.2 to 1.45 s).
4. The sheets draw back in (1.4 to 1.8 s).

So the page never has to reset the icon. Firing again while it's still playing jumps to `Copied again`, which uses the same animation from the beginning, so every copy is confirmed even when the user clicks twice quickly. The tooltip timer uses the same 1.8 s so the text and the drawing finish together.

### Copy first, animate after

The handler awaits the copy and fires the trigger only if it succeeded. An animation that says "copied" when nothing was copied is worse than none. When the copy fails, the tooltip tells the user how to copy by hand and the field's text is selected for them.

`navigator.clipboard.writeText` needs a secure context and, inside an `<iframe>`, permission from the parent page: `<iframe allow="clipboard-write">`. The live frame on this page has it, so the example uses the Clipboard API. Keep the fallback for embeds you don't control: a hidden `<textarea>` with `document.execCommand('copy')` is deprecated but still covers most of those cases.

### Copying what isn't shown

The secret key's field shows a masked value. Its button copies the real value from `data-secret`, so the key can be copied without revealing it on screen. In a real app, fetch the secret on click from an authenticated endpoint rather than putting it in the HTML.

### Accessibility

- Each icon sits in a `<button>` with a specific `aria-label`: "Copy publishable key", "Copy install command". Several buttons that all say "Copy" are hard to tell apart in a screen reader's list of controls.
- The tooltip is `aria-hidden`, because it repeats the label. The confirmation goes to a `role="status"` live region instead ("Publishable key copied").
- The canvas has `pointer-events: none`. The `copy` file's own click also fires `copy` and sends a `copy` event, which you'd use if the icon stood alone.

## React

The React tab captures the player with `onReady` and calls `fire('copy')` after the copy succeeds. Here it is in these docs:

```jsx live
function CopyField() {
  const icon = React.useRef(null)
  const [copied, setCopied] = React.useState(false)
  const value = 'nw_pub_7f3a9c2e81b44d0e9a6c'
  async function copy() {
    try { await navigator.clipboard.writeText(value) } catch { return }
    icon.current?.fire('copy')
    setCopied(true)
    setTimeout(() => setCopied(false), 1800)
  }
  return (
    <div style={{ display: 'flex', alignItems: 'center', gap: 8, maxWidth: 420, height: 44, paddingLeft: 12, border: '1px solid var(--t-line)', borderRadius: 10 }}>
      <code style={{ flex: 1, border: 0, background: 'none', padding: 0 }}>{value}</code>
      <span aria-live="polite" style={{ fontSize: 13, color: 'var(--t-muted)' }}>{copied ? 'Copied' : ''}</span>
      <button type="button" aria-label="Copy publishable key" onClick={copy} style={{ display: 'grid', placeItems: 'center', width: 40, height: 40, padding: 0, border: 0, background: 'transparent', color: 'inherit', cursor: 'pointer' }}>
        <Lite ref={icon} src="copy" ink="auto" style={{ width: 34, height: 34, pointerEvents: 'none' }} />
      </button>
    </div>
  )
}
```

## Make it yours

- **Start from the template.** In the editor, **Add → Templates → Lite: Copy button** opens this exact `copy` component as a new scene. Restyle it (colours, stroke widths, timing, shapes), keep the input and Property names, then use **Export → Animation → Toasty Lite (.json)** and replace `/toasty/lite/copy.json` with your file. The page code on this page works unchanged.
- **Colours.** The sheets follow `ink`. In the example the buttons use the muted text colour, and `ink="currentColor"` picks it up. The element reads the colour when it loads and again when the page theme changes, not on every hover; to recolour on hover, call `icon.player.set('ink', '#18181b')` from your hover handler. The check is a fixed green.
- **Share links.** The same button works for "Copy link" on a share sheet. Copy `location.href` or a short URL from your API.
- **Timing.** The round trip is baked into the `Copied` animation. For a longer confirmation, move the last two groups of keys later in the editor and update the 1800 ms timer to match.
- **Your own icon.** Keep a Trigger named `copy` and two states that alternate on it (`Copied` and `Copied again`) so repeated clicks replay. Export with **Export → Animation → Toasty Lite (.json)**. See [Authoring for Lite](../runtimes/authoring.mdx).
